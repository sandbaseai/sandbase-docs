# Deployment resources (retired)

Deployment and DeploymentRun resources have been retired and are no longer served.

Use the [Schedules API](/api-reference/schedules/) for cron-based and manually triggered Runs, and the [Services API](/api-reference/services/) for on-demand Runs.
