# Primeiros passos com o SandBase {#getting-started-with-sandbase}

O SandBase ajuda seu Agent a se conectar com o mundo real.

Se você está começando agora, comece pelo [Quickstart](/getting-started/quickstart): crie uma conta, configure uma organização e faça uma requisição real.

Depois disso, você pode usar o SandBase de quatro formas:

| Caminho | Ideal para | O que você obtém |
|---|---|---|
| **Chamar modelos e APIs** | Desenvolvedores e builders | Uma requisição funcionando que você pode chamar a partir da sua aplicação |
| **Usar no site** | Experimentar um recurso no navegador | Uma página de detalhes do catálogo que você pode executar sem escrever código |
| **Setup** | Quem usa Codex, Claude, Cursor ou Kiro | Modelos e APIs úteis dentro do seu app de IA |
| **Build Agent** | FDEs e equipes que criam fluxos de trabalho reutilizáveis | Um Agent que você pode testar e executar em Sessions |

## Conceitos principais {#core-ideas}

### Catálogo {#catalog}
O catálogo no site do SandBase é onde você encontra recursos:

- **Models** para raciocínio, texto, imagem, áudio e vídeo
- **APIs** para busca, scraping, dados, mídia, SaaS e conectores
- **Agents** como exemplos prontos que você pode testar ou clonar
- **Skills** como pacotes de tarefas reutilizáveis para Agents

### Setup {#setup}

O Setup coloca recursos na ferramenta de IA que você já usa.

Use-o quando quiser ferramentas disponíveis no Codex, Claude, Cursor ou Kiro sem criar um novo Agent do zero.

### Build Agent {#build-agent}

Em Build Agent você define e testa o seu próprio Agent.

Um Agent combina um modelo, instruções, Skills e ferramentas MCP em uma unidade reutilizável e versionada.

Depois que ele estiver funcionando, você pode:

- executá-lo em Sessions a partir da sua aplicação
- revisar cada Session no Console

## Por onde começar? {#where-should-i-start}

Se você ainda não tem uma conta, comece pelo [Quickstart](/getting-started/quickstart).

Se você quer chamar um recurso a partir do código, navegue pelo [catálogo de modelos](https://www.sandbase.ai/models) ou pelo [catálogo de APIs](https://www.sandbase.ai/apis) e, depois, use a documentação e o exemplo de requisição correspondentes.

Se você quer experimentar um recurso no navegador primeiro, abra uma página de detalhes do catálogo em [sandbase.ai](https://www.sandbase.ai/models).

Se você quer ferramentas no seu app de IA, comece pelo [Setup](/setup/).

Se você quer um fluxo de trabalho repetível, comece por [Build Agent](/agents/).
