# Primi passi con SandBase {#getting-started-with-sandbase}

SandBase aiuta il tuo Agent a connettersi al mondo reale.

Se sei alle prime armi, inizia dal [Quickstart](/getting-started/quickstart): crea un account, configura un'organizzazione e poi invia una richiesta reale.

Dopodiché puoi usare SandBase in quattro modi:

| Percorso | Ideale per | Cosa ottieni |
|---|---|---|
| **Chiamare modelli e API** | Sviluppatori e builder | Una richiesta funzionante da chiamare dalla tua applicazione |
| **Usare il sito web** | Provare una funzionalità nel browser | Una pagina di dettaglio del catalogo da eseguire senza scrivere codice |
| **Setup** | Chi usa Codex, Claude, Cursor o Kiro | Modelli e API utili dentro la tua app di AI |
| **Build Agent** | FDE e team che creano flussi di lavoro riutilizzabili | Un Agent da testare ed eseguire nelle Session |

## Concetti chiave {#core-ideas}

### Catalogo {#catalog}
Il catalogo sul sito di SandBase è il punto in cui trovi le funzionalità:

- **Modelli** per ragionamento, testo, immagini, audio e video
- **API** per ricerca, scraping, dati, media, SaaS e connettori
- **Agent** come esempi pronti all'uso da testare o clonare
- **Skill** come pacchetti di task riutilizzabili per gli Agent

### Setup {#setup}

Setup porta le funzionalità nello strumento di AI che usi già.

Usalo quando vuoi avere tool disponibili in Codex, Claude, Cursor o Kiro senza costruire un nuovo Agent da zero.

### Build Agent {#build-agent}

Build Agent è il punto in cui definisci e testi il tuo Agent.

Un Agent combina un modello, istruzioni, Skill e tool MCP in un'unica unità riutilizzabile e versionata.

Quando funziona, puoi:

- eseguirlo nelle Session dalla tua applicazione
- esaminare ogni Session nella Console

## Da dove inizio? {#where-should-i-start}

Se non hai ancora un account, inizia dal [Quickstart](/getting-started/quickstart).

Se vuoi chiamare una funzionalità dal codice, sfoglia il [catalogo dei modelli](https://www.sandbase.ai/models) o il [catalogo delle API](https://www.sandbase.ai/apis) aggiornati, poi usa la documentazione e l'esempio di richiesta corrispondenti.

Se vuoi prima provare una funzionalità nel browser, apri una pagina di dettaglio del catalogo su [sandbase.ai](https://www.sandbase.ai/models).

Se vuoi dei tool nella tua app di AI, inizia da [Setup](/setup/).

Se vuoi un flusso di lavoro ripetibile, inizia da [Build Agent](/agents/).
