apiReference:
  title: Invia input alla Session
  operation: Sessions
  method: POST
  path: /v1/agents/sessions/{session_id}/events
  description: "Invia esattamente un evento per richiesta: agent.session.input.message o agent.session.input.cancel. Restituisce 202 senza corpo; segui l'avanzamento sullo stream di eventi. La forma estesa di SandBase {\"input\": \"…\", \"file_ids\": [...]} invia testo con fino a 10 allegati pronti e non può essere combinata con events. Un 409 session_input_pending indica che un input precedente è ancora in consegna: attendi e non reinviarlo con una nuova chiave."
  groups:
    - title: Parametri di percorso
      fields:
        - name: session_id
          type: string
          required: true
          description: ID della Session (prefisso ses_).
    - title: Header
      fields:
        - name: Idempotency-Key
          type: string
          required: false
          description: Facoltativo ma consigliato. Riusa la stessa chiave quando ripeti lo stesso input.
    - title: Corpo della richiesta
      description: events oppure input/file_ids.
      fields:
        - name: events
          type: array
          required: false
          description: Esattamente un evento. input.message porta l'input come testo o come un unico messaggio user di tipo input_text; input.cancel non porta input.
        - name: input
          type: string
          required: false
          description: Estensione SandBase. Testo non vuoto fino a 256 KiB.
        - name: file_ids
          type: array
          required: false
          description: Estensione SandBase. Fino a 10 ID di allegati distinti con stato ready.
