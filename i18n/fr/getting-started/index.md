# Bien démarrer avec SandBase {#getting-started-with-sandbase}

SandBase aide votre Agent à se connecter au monde réel.

Si vous débutez, commencez par le [démarrage rapide](/getting-started/quickstart) : créez un compte, configurez une organisation, puis effectuez une vraie requête.

Ensuite, vous pouvez utiliser SandBase de quatre façons :

| Parcours | Idéal pour | Ce que vous obtenez |
|---|---|---|
| **Appeler des modèles et des API** | Développeurs et créateurs | Une requête fonctionnelle que vous pouvez appeler depuis votre application |
| **Utiliser le site web** | Essayer une fonctionnalité dans le navigateur | Une page de détail du catalogue que vous pouvez exécuter sans écrire de code |
| **Setup** | Utilisateurs de Codex, Claude, Cursor ou Kiro | Des modèles et des API utiles directement dans votre application d'IA |
| **Build Agent** | FDE et équipes qui créent des workflows réutilisables | Un Agent que vous pouvez tester et exécuter dans des Sessions |

## Notions clés {#core-ideas}

### Catalogue {#catalog}
Le catalogue du site web SandBase vous permet de trouver des fonctionnalités :

- **Models** pour le raisonnement, le texte, l'image, l'audio et la vidéo
- **APIs** pour la recherche, le scraping, les données, les médias, le SaaS et les connecteurs
- **Agents** : des exemples prêts à l'emploi que vous pouvez tester ou cloner
- **Skills** : des packages de tâches réutilisables pour les Agents

### Setup {#setup}

Setup intègre des fonctionnalités dans l'outil d'IA que vous utilisez déjà.

Utilisez-le lorsque vous voulez disposer d'outils dans Codex, Claude, Cursor ou Kiro sans créer un nouvel Agent de zéro.

### Build Agent {#build-agent}

Build Agent est l'endroit où vous définissez et testez votre propre Agent.

Un Agent réunit un modèle, des instructions, des Skills et des outils MCP en une seule unité réutilisable et versionnée.

Une fois qu'il fonctionne, vous pouvez :

- l'exécuter dans des Sessions depuis votre application
- examiner chaque Session dans la Console

## Par où commencer ? {#where-should-i-start}

Si vous n'avez pas encore de compte, commencez par le [démarrage rapide](/getting-started/quickstart).

Si vous voulez appeler une fonctionnalité depuis votre code, parcourez le [catalogue de modèles](https://www.sandbase.ai/models) ou le [catalogue d'API](https://www.sandbase.ai/apis), puis utilisez la documentation et l'exemple de requête correspondants.

Si vous voulez d'abord essayer une fonctionnalité dans le navigateur, ouvrez une page de détail du catalogue sur [sandbase.ai](https://www.sandbase.ai/models).

Si vous voulez des outils dans votre application d'IA, commencez par [Setup](/setup/).

Si vous voulez un workflow reproductible, commencez par [Build Agent](/agents/).
