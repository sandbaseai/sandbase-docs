# Erste Schritte mit SandBase {#getting-started-with-sandbase}

SandBase verbindet deinen Agent mit der realen Welt.

Wenn du neu bist, beginne mit dem [Quickstart](/getting-started/quickstart): Erstelle ein Konto, richte eine Organisation ein und sende dann eine echte Anfrage.

Danach kannst du SandBase auf vier Arten nutzen:

| Weg | Geeignet für | Was du bekommst |
|---|---|---|
| **Models und APIs aufrufen** | Entwickler und Builder | Eine funktionierende Anfrage, die du aus deiner Anwendung aufrufen kannst |
| **Auf der Website nutzen** | Eine Fähigkeit im Browser ausprobieren | Eine Detailseite im Katalog, die du ohne Code ausführen kannst |
| **Setup** | Nutzer von Codex, Claude, Cursor oder Kiro | Nützliche Models und APIs direkt in deiner KI-App |
| **Build Agent** | FDEs und Teams, die wiederverwendbare Workflows bauen | Einen Agent, den du in Sessions testen und ausführen kannst |

## Grundkonzepte {#core-ideas}

### Katalog {#catalog}
Im Katalog auf der SandBase-Website findest du Fähigkeiten:

- **Models** für Reasoning, Text, Bild, Audio und Video
- **APIs** für Suche, Scraping, Daten, Medien, SaaS und Connectors
- **Agents** als fertige Beispiele, die du testen oder klonen kannst
- **Skills** als wiederverwendbare Aufgabenpakete für Agents

### Setup {#setup}

Setup bringt Fähigkeiten in das KI-Tool, das du bereits verwendest.

Nutze es, wenn du Tools in Codex, Claude, Cursor oder Kiro verfügbar machen willst, ohne einen neuen Agent von Grund auf zu bauen.

### Build Agent {#build-agent}

In Build Agent definierst und testest du deinen eigenen Agent.

Ein Agent kombiniert ein Modell, Anweisungen, Skills und MCP-Tools zu einer wiederverwendbaren, versionierten Einheit.

Sobald er funktioniert, kannst du:

- ihn aus deiner Anwendung in Sessions ausführen
- jede Session in der Console prüfen

## Wo fange ich an? {#where-should-i-start}

Wenn du noch kein Konto hast, beginne mit dem [Quickstart](/getting-started/quickstart).

Wenn du eine Fähigkeit aus Code aufrufen willst, durchsuche den aktuellen [Modellkatalog](https://www.sandbase.ai/models) oder [API-Katalog](https://www.sandbase.ai/apis) und verwende dann die passende Dokumentation und das passende Anfragebeispiel.

Wenn du eine Fähigkeit zuerst im Browser ausprobieren willst, öffne eine Detailseite im Katalog auf [sandbase.ai](https://www.sandbase.ai/models).

Wenn du Tools in deiner KI-App haben willst, beginne mit [Setup](/setup/).

Wenn du einen wiederholbaren Workflow willst, beginne mit [Build Agent](/agents/).
