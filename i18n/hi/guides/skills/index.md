# Skill ट्यूटोरियल {#skill-tutorials}

Videos, animations, maps और अन्य projects बनाने के लिए अपने local AI agent के साथ SandBase Skills का उपयोग करें। [SandBase Lab](https://www.sandbase.ai/lab/) में उदाहरण देखें, कोई Skill download करें, और उसका workflow अपने working folder में चलाएँ।

## ट्यूटोरियल {#tutorials}

| Tutorial | Workflow |
|---|---|
| [Skill को locally इस्तेमाल करें](/guides/skills/local-use) | Skill download करें, SandBase connect करें, brief दें और result सहेजें। |
| [AI City Remix में भाग लें](/guides/skills/ai-city-remix) | Event credits claim करें, शहर और Skill चुनें, video बनाएँ और उसे review के लिए submit करें। |

## अपना workspace तैयार करें {#prepare-your-workspace}

- एक SandBase account।
- आपके computer पर command execution और file access वाला एक AI agent।
- Skill package, inputs और generated files के लिए एक working folder।

Agent, Skill को locally चलाता है और model calls के लिए SandBase का उपयोग करता है। [Setup](/setup/) से अपना connection configure करें और [Billing](https://www.sandbase.ai/console/billing) में usage देखें।
