# SandBase के साथ शुरुआत {#getting-started-with-sandbase}

SandBase आपके Agent को असली दुनिया से जुड़ने में मदद करता है।

अगर आप नए हैं, तो [Quickstart](/getting-started/quickstart) से शुरू करें: एक account बनाएँ, एक organization सेट करें, फिर एक असली request करें।

इसके बाद, आप SandBase को चार तरीकों से इस्तेमाल कर सकते हैं:

| रास्ता | किसके लिए सबसे अच्छा | आपको क्या मिलता है |
|---|---|---|
| **Models और APIs call करें** | Developers और builders | एक काम करने वाला request जिसे आप अपनी application से call कर सकते हैं |
| **Website पर इस्तेमाल करें** | Browser में किसी क्षमता को आज़माना | एक catalog detail पेज जिसे आप code लिखे बिना चला सकते हैं |
| **Setup** | Codex, Claude, Cursor या Kiro इस्तेमाल करने वाले लोग | आपकी AI app के अंदर उपयोगी Models और APIs |
| **Build Agent** | FDEs और दोबारा इस्तेमाल होने वाले workflows बनाने वाली teams | एक Agent जिसे आप Sessions में test और run कर सकते हैं |

## मुख्य अवधारणाएँ {#core-ideas}

### कैटलॉग {#catalog}
SandBase website पर catalog वह जगह है जहाँ आप क्षमताएँ खोजते हैं:

- reasoning, text, image, audio और video के लिए **Models**
- search, scrape, data, media, SaaS और connectors के लिए **APIs**
- तैयार उदाहरणों के रूप में **Agents**, जिन्हें आप test या clone कर सकते हैं
- Agents के लिए दोबारा इस्तेमाल होने वाले task packages के रूप में **Skills**

### सेटअप {#setup}

Setup क्षमताओं को उस AI tool में डालता है जिसे आप पहले से इस्तेमाल करते हैं।

इसे तब इस्तेमाल करें जब आप शुरुआत से नया Agent बनाए बिना Codex, Claude, Cursor या Kiro के अंदर tools उपलब्ध चाहते हों।

### Agent बनाएँ {#build-agent}

Build Agent वह जगह है जहाँ आप अपना Agent परिभाषित और test करते हैं।

एक Agent Model, instructions, Skills और MCP tools को एक दोबारा इस्तेमाल होने वाली, versioned इकाई में जोड़ता है।

इसके काम करने के बाद, आप:

- इसे अपनी application से Sessions में चला सकते हैं
- Console में हर Session की समीक्षा कर सकते हैं

## मुझे कहाँ से शुरू करना चाहिए? {#where-should-i-start}

अगर आपके पास अभी account नहीं है, तो [Quickstart](/getting-started/quickstart) से शुरू करें।

अगर आप code से किसी एक क्षमता को call करना चाहते हैं, तो live [Models catalog](https://www.sandbase.ai/models) या [APIs catalog](https://www.sandbase.ai/apis) देखें, फिर संबंधित documentation और request उदाहरण इस्तेमाल करें।

अगर आप पहले browser में किसी क्षमता को आज़माना चाहते हैं, तो [sandbase.ai](https://www.sandbase.ai/models) पर एक catalog detail पेज खोलें।

अगर आप अपनी AI app में tools चाहते हैं, तो [Setup](/setup/) से शुरू करें।

अगर आप दोहराने योग्य workflow चाहते हैं, तो [Build Agent](/agents/) से शुरू करें।
