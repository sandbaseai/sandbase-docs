# Account API {#account-api}

Account エンドポイントは読み取り専用で、Bearer API キーから特定された組織を対象に動作します。

| 操作 | エンドポイント |
|---|---|
| [残高の取得](./balance) | `GET /v1/account/balance` |
| [実行履歴の一覧](./history) | `GET /v1/account/history` |

残高とコストの値は正確な 10 進数の文字列です。2 進浮動小数点演算で変換せず、
10 進数の値のまま扱ってください。

実行履歴は、直近の運用状況の確認を目的としています。長期的な会計上の照合には、
請求記録またはエクスポートを使用してください。

履歴のフィルタリングには UTC のタイムスタンプがそのまま使われます。`request_id` を指定しない場合、任意の互換パラメーター `timezone` は IANA タイムゾーン名として検証されますが、レスポンスのタイムスタンプは変換されません。`request_id` 完全一致モードでは、他のフィルターとともに無視されます。不明な `type` の値では実行タイプのフィルターが適用されません。有効なフィルターには `multimodal`、`llm`、または `api` を使用してください。サポートされていない `range` の値は `7d` にフォールバックします。

履歴のエントリには、保存されたリクエストパラメーターやモデルの出力が含まれる場合があります。それに応じて API キーへのアクセスを制限し、
機密データが含まれていないか確認せずに、履歴のレスポンスをログやサポートチケットにコピーしないでください。
