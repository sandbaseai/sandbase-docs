# Skill チュートリアル {#skill-tutorials}

SandBase の Skill をローカルの AI エージェントと組み合わせて、動画、アニメーション、地図などのプロジェクトを作成できます。[SandBase Lab](https://www.sandbase.ai/lab/) で例を閲覧し、Skill をダウンロードして、自分の作業フォルダーでそのワークフローを実行します。

## チュートリアル {#tutorials}

| チュートリアル | ワークフロー |
|---|---|
| [Skill をローカルで使う](/guides/skills/local-use) | Skill をダウンロードし、SandBase に接続し、指示内容を伝えて、結果を保存します。 |
| [AI City Remix に参加する](/guides/skills/ai-city-remix) | イベントクレジットを受け取り、都市と Skill を選び、動画を作成して審査に提出します。 |

## ワークスペースの準備 {#prepare-your-workspace}

- SandBase アカウント。
- コマンド実行とファイルアクセスが可能な、コンピューター上の AI エージェント。
- Skill パッケージ、入力、生成ファイルを置く作業フォルダー。

エージェントは Skill をローカルで実行し、モデルの呼び出しに SandBase を使用します。接続は [セットアップ](/setup/) で設定し、使用量は [請求](https://www.sandbase.ai/console/billing) で確認してください。
