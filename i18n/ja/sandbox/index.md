# Sandbox の概要と機能 {#sandbox-overview-and-capabilities}

Sandbox は、コマンドの実行、コードの実行、ファイルの読み書きを行うための隔離された環境を提供します。インスタンスを一時停止して再接続し、ファイルを読み戻すことで永続性を確認できます。

[クイックスタート / E2B SDK](./quickstart) · [Playground を開く（試験運用）](./playground)

アプリケーションに Sandbox を統合するには、[公式の E2B SDK](./quickstart) を使用します。[Sandbox Console](https://www.sandbase.ai/console/sandboxes) にサインインすると、Sandbox の作成や、インスタンスのステータス、ログ、メトリクスの確認ができます。概要については [Sandbox 製品概要](https://www.sandbase.ai/sandbox) を参照してください。以下のウォークスルーと対応表では、別機能である試験運用版の Playground について説明します。

## 5 分でわかる Playground ウォークスルー {#a-five-minute-playground-walkthrough}

1. Sandbox の権限を持つ [API キー](/getting-started/api-keys) を入力します。接続時はテンプレートとインスタンスの読み取りのみが行われます。
2. 利用可能なテンプレートを選び、リソースに関する注意事項に同意して、短時間のインスタンスを作成します。
3. システム情報または Python のサンプルを実行します。コマンドパネルの横で出力とプロセスイベントを確認できます。
4. テキストファイルを書き込んで確認し、インスタンスを一時停止してから再開し、同じファイルを再度読み取ります。
5. ライフサイクルイベント、メトリクス、ログ、マシン時間の記録を確認します。終わったらインスタンスを削除してください。

ページを更新すると、ページ上の認証情報とローカルの操作履歴は消去されますが、Sandbox は削除されません。実行中のインスタンスはサーバーのタイムアウトに従います。一時停止したインスタンスはリソースを保持し続ける場合があります。インスタンス ID を記録しておき、ページを離れた後に組織のツールでリソースを照合してクリーンアップしてください。

## 機能と制限 {#capabilities-and-boundaries}

| 機能 | Playground での対応 |
| --- | --- |
| 作成、一覧表示、一時停止、再開、タイムアウトの延長、削除 | 利用可能。変更操作はこのページのセッションで作成したインスタンスにのみ適用されます |
| コマンドとテキストファイル | 利用可能。コマンドの実行は最大 25 秒、ファイル編集は `/tmp/` 内かつ 32 KiB までに制限されます |
| ライフサイクルイベント、ログ、メトリクス、マシン時間 | 環境によって異なります。返された結果を確認してください |
| AI チャットと会話コンテキスト | 統合されていません。モデルの設定と Agent のワークロードが必要です |
| PTY、アプリケーションポート、Webhook、テンプレートのビルド | このインターフェースでは利用できません |
| スナップショットとフォーク | この Playground では利用できません |

シェルの操作は AI チャットではありません。インスタンスの復旧、ファイルの永続性、プロセスの存続、会話の継続性は、それぞれ別に確認する必要があります。

## イベントについて {#understanding-events}

**Sandbox lifecycle** のエントリは、更新時に取得されるサーバーのネイティブイベントで、遅れて届くことがあります。**Sandbox process** のエントリは、プロセスの開始とストリーミング出力を表します。**Playground** のエントリはローカルのリクエストの完了または失敗を記録するもので、サービスのライフサイクルイベントではありません。

一覧が空でも使用量がゼロとは限らず、イベントがなくても操作が失敗したとは限りません。マシン時間の記録は最終的な請求額ではありません。タイムアウトや接続の中断が発生した場合は、再度作成リクエストを送る前にインスタンスを照合してください。

## テンプレートの表示 {#template-visibility}

テンプレートは公開または組織内限定にできます。数は固定ではありません。名前のないエントリも表示され、代わりにエイリアスまたは ID がラベルとして使われます。表示・使用できるテンプレートは、組織のアクセス権とテンプレートの提供状況によって決まります。

## Sandbox と Agent Session {#sandboxes-and-agent-sessions}

Agents の Session は SandBase のホスト型クラウドで実行されます。E2B SDK で作成する Sandbox インスタンスとは別のもので、Agents API は Sandbox インスタンスを公開しません。[Sessions](/agents/sessions) を参照してください。
