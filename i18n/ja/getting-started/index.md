# SandBase を始める {#getting-started-with-sandbase}

SandBase は、あなたの Agent を現実世界につなぎます。

初めての方は [Quickstart](/getting-started/quickstart) から始めてください。アカウントを作成し、組織を設定してから、実際のリクエストを 1 回送信します。

その後は、次の 4 つの方法で SandBase を利用できます。

| 方法 | 向いている用途 | 得られるもの |
|---|---|---|
| **Models と API を呼び出す** | 開発者やビルダー | アプリケーションから呼び出せる、動作するリクエスト |
| **Web サイトで使う** | ブラウザーで機能を試す | コードを書かずに実行できるカタログの詳細ページ |
| **Setup** | Codex、Claude、Cursor、Kiro を使っている方 | AI アプリ内で使える便利な Models と API |
| **Build Agent** | 再利用可能なワークフローを構築する FDE やチーム | Session でテスト・実行できる Agent |

## 基本的な考え方 {#core-ideas}

### カタログ {#catalog}
SandBase の Web サイトにあるカタログで、利用できる機能を探せます。

- 推論、テキスト、画像、音声、動画向けの **Models**
- 検索、スクレイピング、データ、メディア、SaaS、コネクター向けの **API**
- テストやクローンができる既製の例としての **Agents**
- Agent 向けの再利用可能なタスクパッケージとしての **Skills**

### Setup {#setup}

Setup は、すでに使っている AI ツールに機能を組み込みます。

新しい Agent を一から作らずに、Codex、Claude、Cursor、Kiro の中でツールを使いたい場合に利用してください。

### Build Agent {#build-agent}

Build Agent では、独自の Agent を定義してテストします。

Agent は、Model、instructions、Skills、MCP ツールを、再利用可能でバージョン管理された 1 つの単位にまとめたものです。

動作したら、次のことができます。

- アプリケーションから Session で実行する
- Console で各 Session を確認する

## どこから始めればよいですか？ {#where-should-i-start}

まだアカウントがない場合は、[Quickstart](/getting-started/quickstart) から始めてください。

コードから 1 つの機能を呼び出したい場合は、最新の [Models カタログ](https://www.sandbase.ai/models)または [API カタログ](https://www.sandbase.ai/apis)を参照し、対応するドキュメントとリクエスト例を使ってください。

まずブラウザーで機能を試したい場合は、[sandbase.ai](https://www.sandbase.ai/models) でカタログの詳細ページを開いてください。

AI アプリでツールを使いたい場合は、[Setup](/setup/) から始めてください。

繰り返し使えるワークフローが必要な場合は、[Build Agent](/agents/) から始めてください。
