# Memulai dengan SandBase {#getting-started-with-sandbase}

SandBase membantu Agent Anda terhubung ke dunia nyata.

Mulailah dengan [Quickstart](/getting-started/quickstart) jika Anda baru: buat akun, siapkan organisasi, lalu buat satu permintaan sungguhan.

Setelah itu, Anda dapat menggunakan SandBase dengan empat cara:

| Jalur | Paling cocok untuk | Yang Anda dapatkan |
|---|---|---|
| **Memanggil Models dan API** | Developer dan builder | Permintaan yang berfungsi dan dapat dipanggil dari aplikasi Anda |
| **Menggunakan di situs web** | Mencoba kemampuan di browser | Halaman detail katalog yang dapat dijalankan tanpa menulis kode |
| **Setup** | Pengguna Codex, Claude, Cursor, atau Kiro | Models dan API yang berguna di dalam aplikasi AI Anda |
| **Build Agent** | FDE dan tim yang membangun alur kerja yang dapat digunakan ulang | Agent yang dapat diuji dan dijalankan di Session |

## Konsep inti {#core-ideas}

### Katalog {#catalog}
Katalog di situs web SandBase adalah tempat Anda menemukan kemampuan:

- **Models** untuk reasoning, teks, gambar, audio, dan video
- **API** untuk search, scrape, data, media, SaaS, dan konektor
- **Agents** sebagai contoh siap pakai yang dapat Anda uji atau clone
- **Skills** sebagai paket tugas yang dapat digunakan ulang untuk Agent

### Setup {#setup}

Setup menempatkan kemampuan ke dalam tool AI yang sudah Anda gunakan.

Gunakan Setup jika Anda ingin tool tersedia di dalam Codex, Claude, Cursor, atau Kiro tanpa membangun Agent baru dari awal.

### Build Agent {#build-agent}

Build Agent adalah tempat Anda mendefinisikan dan menguji Agent Anda sendiri.

Agent menggabungkan Model, instruksi, Skills, dan tool MCP menjadi satu unit yang dapat digunakan ulang dan memiliki versi.

Setelah Agent berfungsi, Anda dapat:

- menjalankannya di Session dari aplikasi Anda
- meninjau setiap Session di Console

## Harus mulai dari mana? {#where-should-i-start}

Jika Anda belum memiliki akun, mulailah dengan [Quickstart](/getting-started/quickstart).

Jika Anda ingin memanggil satu kemampuan dari kode, jelajahi [katalog Models](https://www.sandbase.ai/models) atau [katalog API](https://www.sandbase.ai/apis) yang terkini, lalu gunakan dokumentasi dan contoh permintaan yang sesuai.

Jika Anda ingin mencoba kemampuan di browser terlebih dahulu, buka halaman detail katalog di [sandbase.ai](https://www.sandbase.ai/models).

Jika Anda menginginkan tool di aplikasi AI Anda, mulailah dengan [Setup](/setup/).

Jika Anda menginginkan alur kerja yang dapat diulang, mulailah dengan [Build Agent](/agents/).
