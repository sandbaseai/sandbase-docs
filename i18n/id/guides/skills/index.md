# Tutorial Skill {#skill-tutorials}

Gunakan SandBase Skills dengan agen AI lokal Anda untuk membuat video, animasi, peta, dan proyek lainnya. Telusuri contoh di [SandBase Lab](https://www.sandbase.ai/lab/), unduh Skill, lalu jalankan alur kerjanya di folder kerja Anda sendiri.

## Tutorial {#tutorials}

| Tutorial | Alur kerja |
|---|---|
| [Menggunakan Skill secara lokal](/guides/skills/local-use) | Unduh Skill, hubungkan SandBase, berikan brief, dan simpan hasilnya. |
| [Ikut AI City Remix](/guides/skills/ai-city-remix) | Klaim kredit event, pilih kota dan Skill, buat video, lalu kirimkan untuk ditinjau. |

## Siapkan workspace Anda {#prepare-your-workspace}

- Akun SandBase.
- Agen AI di komputer Anda dengan kemampuan menjalankan perintah dan mengakses file.
- Folder kerja untuk paket Skill, input, dan file yang dihasilkan.

Agen menjalankan Skill secara lokal dan menggunakan SandBase untuk panggilan model. Konfigurasikan koneksi Anda melalui [Penyiapan](/setup/) dan tinjau penggunaan di [Billing](https://www.sandbase.ai/console/billing).
