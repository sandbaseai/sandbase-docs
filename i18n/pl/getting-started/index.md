# Pierwsze kroki z SandBase {#getting-started-with-sandbase}

SandBase pomaga Twojemu Agentowi łączyć się z prawdziwym światem.

Jeśli dopiero zaczynasz, przejdź do [Quickstart](/getting-started/quickstart): załóż konto, skonfiguruj organizację, a następnie wykonaj jedno prawdziwe żądanie.

Potem możesz korzystać z SandBase na cztery sposoby:

| Ścieżka | Dla kogo | Co otrzymujesz |
|---|---|---|
| **Wywoływanie modeli i API** | Programiści i twórcy | Działające żądanie, które możesz wywołać z aplikacji |
| **Korzystanie na stronie** | Wypróbowanie możliwości w przeglądarce | Strona szczegółów w katalogu, którą uruchomisz bez pisania kodu |
| **Setup** | Osoby korzystające z Codex, Claude, Cursor lub Kiro | Przydatne modele i API w Twojej aplikacji AI |
| **Build Agent** | FDE i zespoły budujące przepływy wielokrotnego użytku | Agent, którego możesz testować i uruchamiać w Sessions |

## Podstawowe pojęcia {#core-ideas}

### Katalog {#catalog}
W katalogu na stronie SandBase znajdziesz dostępne możliwości:

- **Models** do rozumowania, tekstu, obrazów, audio i wideo
- **APIs** do wyszukiwania, scrapowania, danych, mediów, SaaS i konektorów
- **Agents** jako gotowe przykłady, które możesz testować lub klonować
- **Skills** jako pakiety zadań wielokrotnego użytku dla Agents

### Setup {#setup}

Setup umieszcza możliwości w narzędziu AI, którego już używasz.

Skorzystaj z niego, gdy chcesz mieć narzędzia dostępne w Codex, Claude, Cursor lub Kiro bez budowania nowego Agenta od zera.

### Build Agent {#build-agent}

Build Agent to miejsce, w którym definiujesz i testujesz własnego Agenta.

Agent łączy Model, instrukcje, Skills i narzędzia MCP w jedną wersjonowaną jednostkę wielokrotnego użytku.

Gdy zacznie działać, możesz:

- uruchamiać go w Sessions z poziomu aplikacji
- przeglądać każdą Session w Console

## Od czego zacząć? {#where-should-i-start}

Jeśli nie masz jeszcze konta, zacznij od [Quickstart](/getting-started/quickstart).

Jeśli chcesz wywołać jedną możliwość z kodu, przejrzyj aktualny [katalog modeli](https://www.sandbase.ai/models) lub [katalog API](https://www.sandbase.ai/apis), a następnie skorzystaj z odpowiedniej dokumentacji i przykładowego żądania.

Jeśli chcesz najpierw wypróbować możliwość w przeglądarce, otwórz stronę szczegółów w katalogu na [sandbase.ai](https://www.sandbase.ai/models).

Jeśli chcesz mieć narzędzia w swojej aplikacji AI, zacznij od [Setup](/setup/).

Jeśli potrzebujesz powtarzalnego przepływu pracy, zacznij od [Build Agent](/agents/).
