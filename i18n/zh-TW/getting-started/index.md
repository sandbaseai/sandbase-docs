# 開始使用 SandBase {#getting-started-with-sandbase}

SandBase 協助您的 Agent 與真實世界連結。

如果您是新使用者，請從[快速入門](/getting-started/quickstart)開始：建立帳戶、設定組織，然後送出一個真實的請求。

之後，您可以透過四種方式使用 SandBase：

| 方式 | 適合對象 | 您會得到 |
|---|---|---|
| **呼叫 Models 與 APIs** | 開發者與建構者 | 可從應用程式呼叫的有效請求 |
| **在網站上使用** | 想在瀏覽器中試用功能的人 | 不必撰寫程式碼即可執行的目錄詳細頁面 |
| **Setup** | 使用 Codex、Claude、Cursor 或 Kiro 的人 | 在您的 AI 應用程式中可用的 Models 與 APIs |
| **Build Agent** | 建構可重複使用工作流程的 FDE 與團隊 | 可在 Session 中測試與執行的 Agent |

## 核心概念 {#core-ideas}

### 目錄 {#catalog}
SandBase 網站上的目錄是您尋找功能的地方：

- **Models**：用於推理、文字、圖片、音訊與影片
- **APIs**：用於搜尋、擷取、資料、媒體、SaaS 與連接器
- **Agents**：可測試或複製的現成範例
- **Skills**：供 Agent 使用的可重複使用任務套件

### Setup {#setup}

Setup 會將功能加入您已在使用的 AI 工具中。

當您想在 Codex、Claude、Cursor 或 Kiro 中使用工具，又不想從頭建構新的 Agent 時，就可以使用它。

### Build Agent {#build-agent}

Build Agent 是您定義與測試自己 Agent 的地方。

Agent 將 Model、指示、Skills 與 MCP 工具組合成一個可重複使用、有版本控管的單位。

運作正常後，您可以：

- 從應用程式在 Session 中執行它
- 在 Console 中檢視每個 Session

## 我該從哪裡開始？ {#where-should-i-start}

如果您還沒有帳戶，請從[快速入門](/getting-started/quickstart)開始。

如果您想從程式碼呼叫某項功能，請瀏覽即時的[模型目錄](https://www.sandbase.ai/models)或 [API 目錄](https://www.sandbase.ai/apis)，再參考對應的文件與請求範例。

如果您想先在瀏覽器中試用功能，請在 [sandbase.ai](https://www.sandbase.ai/models) 開啟目錄詳細頁面。

如果您想在 AI 應用程式中使用工具，請從 [Setup](/setup/) 開始。

如果您需要可重複執行的工作流程，請從 [Build Agent](/agents/) 開始。
