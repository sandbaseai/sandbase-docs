# Bắt đầu với SandBase {#getting-started-with-sandbase}

SandBase giúp Agent của bạn kết nối với thế giới thực.

Nếu bạn mới bắt đầu, hãy xem [Quickstart](/getting-started/quickstart): tạo tài khoản, thiết lập tổ chức, rồi thực hiện một request thật.

Sau đó, bạn có thể dùng SandBase theo bốn cách:

| Cách dùng | Phù hợp nhất cho | Bạn nhận được gì |
|---|---|---|
| **Gọi Models và APIs** | Lập trình viên và người xây dựng sản phẩm | Một request hoạt động được mà bạn có thể gọi từ ứng dụng |
| **Dùng trên website** | Thử một khả năng ngay trên trình duyệt | Trang chi tiết trong catalog mà bạn có thể chạy không cần viết code |
| **Setup** | Người dùng Codex, Claude, Cursor hoặc Kiro | Các Models và APIs hữu ích ngay trong ứng dụng AI của bạn |
| **Build Agent** | FDE và các nhóm xây dựng quy trình có thể tái sử dụng | Một Agent bạn có thể kiểm thử và chạy trong Session |

## Khái niệm cốt lõi {#core-ideas}

### Catalog {#catalog}
Catalog trên website SandBase là nơi bạn tìm các khả năng:

- **Models** cho suy luận, văn bản, hình ảnh, âm thanh và video
- **APIs** cho tìm kiếm, scrape, dữ liệu, media, SaaS và connector
- **Agents** là các ví dụ dựng sẵn mà bạn có thể kiểm thử hoặc clone
- **Skills** là các gói tác vụ có thể tái sử dụng cho Agent

### Setup {#setup}

Setup đưa các khả năng vào công cụ AI mà bạn đang dùng.

Hãy dùng Setup khi bạn muốn có công cụ ngay trong Codex, Claude, Cursor hoặc Kiro mà không cần xây dựng Agent mới từ đầu.

### Build Agent {#build-agent}

Build Agent là nơi bạn định nghĩa và kiểm thử Agent của riêng mình.

Agent kết hợp một Model, chỉ dẫn, Skills và công cụ MCP thành một đơn vị có thể tái sử dụng và có phiên bản.

Khi Agent đã hoạt động, bạn có thể:

- chạy nó trong Session từ ứng dụng của bạn
- xem lại từng Session trong Console

## Nên bắt đầu từ đâu? {#where-should-i-start}

Nếu bạn chưa có tài khoản, hãy bắt đầu với [Quickstart](/getting-started/quickstart).

Nếu bạn muốn gọi một khả năng từ code, hãy duyệt [catalog Models](https://www.sandbase.ai/models) hoặc [catalog APIs](https://www.sandbase.ai/apis), rồi dùng tài liệu và ví dụ request tương ứng.

Nếu bạn muốn thử một khả năng trên trình duyệt trước, hãy mở trang chi tiết trong catalog trên [sandbase.ai](https://www.sandbase.ai/models).

Nếu bạn muốn có công cụ trong ứng dụng AI của mình, hãy bắt đầu với [Setup](/setup/).

Nếu bạn muốn một quy trình có thể lặp lại, hãy bắt đầu với [Build Agent](/agents/).
