# Account API {#account-api}

Account 엔드포인트는 읽기 전용이며, Bearer API 키로 식별된 조직을 대상으로 동작합니다.

| 작업 | 엔드포인트 |
|---|---|
| [잔액 조회](./balance) | `GET /v1/account/balance` |
| [실행 기록 목록 조회](./history) | `GET /v1/account/history` |

잔액과 비용 값은 정확한 십진수 문자열입니다. 이진 부동소수점 연산으로 변환하지 말고
십진수 값으로 유지하세요.

실행 기록은 최근 운영 상황을 확인하기 위한 용도입니다. 장기적인 재무 대사에는
청구 기록이나 내보내기를 사용하세요.

기록 필터링은 원시 UTC 타임스탬프를 사용합니다. `request_id`가 없으면 선택적 호환성 파라미터인 `timezone`은 IANA 시간대 이름인지 검증되지만 응답 타임스탬프를 변환하지는 않습니다. 정확한 `request_id` 모드에서는 다른 필터와 함께 이 값이 무시됩니다. 알 수 없는 `type` 값은 실행 유형 필터를 적용하지 않으므로, 필터를 적용하려면 `multimodal`, `llm`, `api` 중 하나를 사용하세요. 지원되지 않는 `range` 값은 `7d`로 대체됩니다.

기록 항목에는 저장된 요청 파라미터와 모델 출력이 포함될 수 있습니다. 이에 맞게 API 키에 대한 접근을 제한하고,
민감한 데이터가 있는지 검토하지 않은 채 기록 응답을 로그나 지원 티켓에 복사하지 마세요.
