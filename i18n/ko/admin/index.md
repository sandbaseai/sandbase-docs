# 계정 및 결제 {#account-and-billing}

조직 설정에서는 사용량의 소유 주체, 애플리케이션의 인증 방식, 지출 모니터링 방식을 관리합니다.

## 관리 항목 {#what-you-manage}

| 영역 | 용도 |
|---|---|
| [조직](/admin/organizations) | 워크스페이스 경계, 멤버, 소유권 관리 |
| [API 키](/getting-started/api-keys) | 애플리케이션 자격 증명 생성, 교체, 폐기 |
| [결제 및 크레딧](/admin/billing) | 잔액 확인, 크레딧 구매, 자동 충전 설정, Activities 및 Analysis에서 사용량 확인 |
| [가격 및 사용량](/guides/billing) | 모델 가격, 일일 무료 API 호출, 작업 1건의 비용 확인 |
| [속도 제한](/guides/rate-limiting) | 요청 한도와 안전한 재시도 방식 이해 |

## 권장 설정 {#recommended-setup}

1. 올바른 조직에서 작업하고 있는지 확인합니다.
2. 개발, 스테이징, 프로덕션용 API 키를 각각 따로 만듭니다.
3. 키 이름은 애플리케이션과 환경에 맞춰 짓습니다.
4. 첫 프로덕션 요청 후 Activities와 결제 내역을 확인합니다.
5. 사용하지 않는 키는 폐기하고, 예상치 못한 사용량은 즉시 조사합니다.

## 소유권 및 접근 {#ownership-and-access}

API 키와 사용량은 조직에 속합니다. 조직을 전환하면 Console에 표시되는 리소스, 키, 결제 컨텍스트가 바뀝니다. 프로덕션 구성을 변경하기 전에 선택된 조직을 확인하고, 해당 키를 사용하는 애플리케이션과 키 교체 일정을 조율하세요.

## 보안 기본 수칙 {#security-basics}

- 키는 환경 변수나 시크릿 관리자에 저장합니다
- 키를 Agent 지시, 소스 코드, 스크린샷, 지원 문의 메시지에 절대 붙여 넣지 않습니다
- 애플리케이션과 환경마다 별도의 키를 사용합니다
- 키가 노출되었을 가능성이 있으면 즉시 폐기합니다
- Activities에서 예상치 못한 요청량, 모델, 엔드포인트를 모니터링합니다
