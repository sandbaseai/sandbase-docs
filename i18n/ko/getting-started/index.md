# SandBase 시작하기 {#getting-started-with-sandbase}

SandBase는 Agent가 현실 세계와 연결되도록 돕습니다.

처음이라면 [빠른 시작](/getting-started/quickstart)부터 시작하세요. 계정을 만들고 조직을 설정한 뒤 실제 요청을 하나 보내 봅니다.

그다음에는 네 가지 방법으로 SandBase를 사용할 수 있습니다.

| 경로 | 적합한 대상 | 얻을 수 있는 것 |
|---|---|---|
| **모델 및 API 호출** | 개발자와 빌더 | 애플리케이션에서 호출할 수 있는 동작하는 요청 |
| **웹사이트에서 사용** | 브라우저에서 기능을 써 보려는 경우 | 코드 없이 실행할 수 있는 카탈로그 상세 페이지 |
| **Setup** | Codex, Claude, Cursor, Kiro 사용자 | AI 앱 안에서 쓸 수 있는 유용한 모델과 API |
| **Build Agent** | 재사용 가능한 워크플로를 만드는 FDE와 팀 | Session에서 테스트하고 실행할 수 있는 Agent |

## 핵심 개념 {#core-ideas}

### 카탈로그 {#catalog}
SandBase 웹사이트의 카탈로그에서 기능을 찾을 수 있습니다.

- 추론, 텍스트, 이미지, 오디오, 비디오용 **모델**
- 검색, 스크래핑, 데이터, 미디어, SaaS, 커넥터용 **API**
- 테스트하거나 복제할 수 있는 기성 예시인 **Agent**
- Agent용 재사용 가능한 작업 패키지인 **Skill**

### Setup {#setup}

Setup은 이미 사용 중인 AI 도구에 기능을 추가합니다.

새 Agent를 처음부터 만들지 않고 Codex, Claude, Cursor, Kiro 안에서 도구를 쓰고 싶을 때 사용하세요.

### Build Agent {#build-agent}

Build Agent에서는 자신만의 Agent를 정의하고 테스트합니다.

Agent는 모델, 지시, Skill, MCP 도구를 재사용 가능하고 버전이 관리되는 하나의 단위로 묶습니다.

Agent가 제대로 동작하면 다음을 할 수 있습니다.

- 애플리케이션에서 Session으로 실행
- Console에서 각 Session 검토

## 어디서부터 시작해야 하나요? {#where-should-i-start}

아직 계정이 없다면 [빠른 시작](/getting-started/quickstart)부터 시작하세요.

코드에서 기능 하나를 호출하려면 [모델 카탈로그](https://www.sandbase.ai/models) 또는 [API 카탈로그](https://www.sandbase.ai/apis)를 둘러본 뒤 해당 문서와 요청 예시를 사용하세요.

먼저 브라우저에서 기능을 써 보려면 [sandbase.ai](https://www.sandbase.ai/models)에서 카탈로그 상세 페이지를 여세요.

AI 앱에서 도구를 쓰려면 [Setup](/setup/)부터 시작하세요.

반복 가능한 워크플로가 필요하다면 [Build Agent](/agents/)부터 시작하세요.
