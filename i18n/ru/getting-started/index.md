# Начало работы с SandBase {#getting-started-with-sandbase}

SandBase помогает вашему Agent взаимодействовать с реальным миром.

Если вы здесь впервые, начните с [Quickstart](/getting-started/quickstart): создайте аккаунт, настройте организацию и выполните один реальный запрос.

После этого SandBase можно использовать четырьмя способами:

| Путь | Для кого | Что вы получаете |
|---|---|---|
| **Вызов моделей и API** | Разработчики и создатели продуктов | Рабочий запрос, который можно вызывать из вашего приложения |
| **Использование на сайте** | Те, кто хочет попробовать возможность в браузере | Страница каталога, которую можно запустить без написания кода |
| **Setup** | Пользователи Codex, Claude, Cursor или Kiro | Полезные модели и API внутри вашего AI-приложения |
| **Build Agent** | FDE и команды, создающие многократно используемые сценарии | Agent, который можно тестировать и запускать в сессиях |

## Основные понятия {#core-ideas}

### Каталог {#catalog}
В каталоге на сайте SandBase можно найти возможности:

- **Models** для рассуждений, текста, изображений, аудио и видео
- **APIs** для поиска, скрейпинга, данных, медиа, SaaS и коннекторов
- **Agents** — готовые примеры, которые можно протестировать или клонировать
- **Skills** — многократно используемые пакеты задач для Agents

### Setup {#setup}

Setup добавляет возможности в AI-инструмент, которым вы уже пользуетесь.

Используйте его, если хотите, чтобы инструменты были доступны в Codex, Claude, Cursor или Kiro без создания нового Agent с нуля.

### Build Agent {#build-agent}

В Build Agent вы определяете и тестируете собственный Agent.

Agent объединяет модель, инструкции, Skills и MCP-инструменты в одну многократно используемую версионируемую единицу.

Когда он заработает, вы можете:

- запускать его в сессиях из своего приложения
- просматривать каждую сессию в Console

## С чего начать? {#where-should-i-start}

Если у вас ещё нет аккаунта, начните с [Quickstart](/getting-started/quickstart).

Если вы хотите вызвать одну возможность из кода, просмотрите актуальный [каталог моделей](https://www.sandbase.ai/models) или [каталог API](https://www.sandbase.ai/apis), а затем воспользуйтесь соответствующей документацией и примером запроса.

Если вы хотите сначала попробовать возможность в браузере, откройте страницу каталога на [sandbase.ai](https://www.sandbase.ai/models).

Если вам нужны инструменты в AI-приложении, начните с [Setup](/setup/).

Если вам нужен повторяемый сценарий, начните с [Build Agent](/agents/).
