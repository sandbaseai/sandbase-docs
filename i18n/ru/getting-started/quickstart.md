# Быстрый старт {#quick-start}

## Выберите, как использовать SandBase {#connect}

Это **три альтернативных способа начать**, а не три обязательных шага. Во всех случаях используйте один и тот же аккаунт и рабочее пространство SandBase.

<QuickstartPaths />

Нужна только готовая задача? [Посмотрите Tools](#use-tools) или [выберите Skill](#use-skills). Публичные каталоги и документацию можно просматривать без входа в аккаунт.

### Начните с репозиториев с открытым исходным кодом {#start-from-the-open-source-repositories}

- **[SandBase — SDK и примеры](https://github.com/sandbaseai/sandbase)**: клиенты для Python, TypeScript и Go, примеры API и процессы для размещённых Agents. Подходит, если вы создаёте собственное приложение.
- **[SandBase CLI и MCP](https://github.com/sandbaseai/cli)**: установка и подключение AI-инструмента, а также поиск и запуск возможностей из терминала. Подходит для работы с вашим существующим агентом.

## Перед началом: войдите в аккаунт {#create-account}

Войдите в аккаунт, прежде чем пользоваться Playground, запускать размещённый Skill или создавать API-ключ. Бесплатными инструментами, которые работают без аккаунта, можно пользоваться сразу. **Уже вошли? Пропустите этот шаг** и убедитесь, что в меню аккаунта показано нужное рабочее пространство.

SandBase использует вход через GitHub или Google. Отдельной регистрации по email и паролю нет.

1. Откройте [Создать аккаунт / Войти](https://www.sandbase.ai/login){target="_blank"}.
2. Пройдите проверку безопасности и выберите **Sign in with GitHub** или **Sign in with Google**.
3. Подтвердите доступ в окне провайдера.
4. Вернитесь на страницу, с которой работали, или откройте [Console](https://www.sandbase.ai/console){target="_blank"}.

При первом входе создаются ваш аккаунт и **личное рабочее пространство**. Чтобы попробовать SandBase, создавать организацию не нужно.

Если вам начислен приветственный кредит, можно начать без добавления способа оплаты. Текущий баланс показан на карточке **Balance** в Dashboard Console и на странице [Billing](https://www.sandbase.ai/console/billing){target="_blank"}.

## На платформе {#use-on-website}

Выберите этот способ, если хотите сначала попробовать модель, API или Agent в браузере — без установки клиента и без кода.

1. Войдите в аккаунт и откройте каталог:
   - [Языковые модели](https://www.sandbase.ai/models){target="_blank"}
   - [Модели изображений и видео](https://www.sandbase.ai/models/image-video){target="_blank"}
   - [API](https://www.sandbase.ai/apis){target="_blank"}
   - [Agents](https://www.sandbase.ai/agents){target="_blank"}
2. Откройте страницу модели или API и выберите **Playground**, если он доступен.
3. Введите необходимые входные данные: промпт, изображение, поисковый запрос или URL. Перед запуском проверьте указанную цену.
4. Выполните запрос и посмотрите возвращённый текст, данные, изображение, видео или статус задачи.

Для Playground на сайте отдельный API-ключ не нужен. Если у возможности нет Playground, перейдите на её вкладку **API** и следуйте описанному ниже пути через API.

## Через API {#call-api}

Выберите этот способ, если добавляете одну возможность в своё приложение.

1. Используйте действующий ключ для нужного рабочего пространства или создайте [API-ключ](/getting-started/api-keys) в разделе [Developer → API Keys](https://www.sandbase.ai/console/keys){target="_blank"} кнопкой **New key**. Сразу скопируйте его: он показывается только один раз.
2. Отфильтруйте каталог и откройте страницу с подробностями:
   - [Языковые модели](https://www.sandbase.ai/models){target="_blank"} — фильтры по провайдеру, возможностям, контексту и цене
   - [Модели изображений и видео](https://www.sandbase.ai/models/image-video){target="_blank"} — фильтры мультимодальных моделей, например text-to-image, image-to-image, text-to-video и image-to-video
   - [API](https://www.sandbase.ai/apis){target="_blank"} — фильтры API-ресурсов по платформе и источнику данных
3. Откройте вкладку **API**, скопируйте пример запроса и заполните обязательные поля этого эндпоинта.
4. Сохраните ключ SandBase в переменной окружения на сервере и выполните запрос. Не размещайте его в браузерном коде или публичном репозитории.
5. Проверьте ответ. Для асинхронной задачи следуйте примеру опроса статуса для этого эндпоинта, пока задача не завершится.

Пример вызова языковой модели для **Bash / zsh** (macOS, Linux или Windows с WSL). Замените ключ-заглушку локально. Для других сред используйте примеры на Python, TypeScript или Go из репозитория ниже; команды оболочки не взаимозаменяемы с PowerShell.

```bash
export SANDBASE_API_KEY="sk-YOUR_KEY"

curl https://api.sandbase.ai/v1/chat/completions \
  -H "Authorization: Bearer $SANDBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek/deepseek-v4-flash",
    "messages": [{"role": "user", "content": "Reply with one sentence explaining what an API is."}]
  }'
```

Начните с кода: [SDK и примеры SandBase на GitHub](https://github.com/sandbaseai/sandbase).

Подробнее: [Первый вызов API](/getting-started/first-call).

## С вашим агентом {#use-in-ai-tool}

Выберите этот способ, если вы пользуетесь Claude Code, Codex, Cursor, Kiro или другим поддерживаемым клиентом и хотите получить модели и API SandBase прямо в нём.

**Для автоматической локальной настройки** клиент должен уметь выполнять команды, а на его машине нужны Node.js 20+ и npm. Если ваш клиент поддерживает только чат, следуйте [инструкциям по подключению для конкретного клиента](/setup/).

1. Откройте [Build → AI tools](https://www.sandbase.ai/console/setup){target="_blank"} в Console.
2. Вставьте эту строку в чат своего AI-ассистента и опишите, что хотите создать. Это инструкция для чата, а не команда оболочки:

   ```text
   set up https://www.sandbase.ai/SKILL.md
   ```

3. Подтвердите вход в браузере, который откроет агент. Вставлять API-ключ не нужно.
4. Начните новую сессию или перезапустите приложение, чтобы загрузились инструменты SandBase.
5. Попросите агента найти и изучить нужный инструмент, а затем выполнить один ограниченный запрос в пределах ваших полномочий и бюджета. При разработке попросите его встроить ответ в проект и предоставить команду запуска и фактические результаты тестов. Одно лишь обнаружение инструмента не подтверждает работоспособность вызова бизнес-API.

Предпочитаете терминал? Выполните `npx -y @sandbaseai/cli@latest connect`. Команда настраивает обнаруженные поддерживаемые клиенты; чтобы настроить только один, используйте `npx -y @sandbaseai/cli@latest connect --client codex` (замените `codex` на свой поддерживаемый клиент). После этого перезапустите клиент. Перед платным запуском проверьте выбранное рабочее пространство.

Например, можно попросить:

> Найди API SandBase для поиска публичных постов в X об ИИ-агентах. Сначала изучи его обязательные входные данные и цену, затем сообщи стоимость одного запроса до запуска. Сохрани в результате ссылки на исходные источники.

Исходный код и инструкции по установке: [SandBase CLI и MCP на GitHub](https://github.com/sandbaseai/cli).

Подробнее: [Подключение AI-инструментов](/setup/).

### Пусть AI-ассистент поможет вам в разработке {#start-with-your-agent}

[Skill настройки](https://www.sandbase.ai/SKILL.md) проводит агента с учётом вашей текущей ситуации: аккаунта ещё нет, есть API-ключ, инструмент уже подключён, есть готовый проект или нужна новая функция. Он проверяет входные данные и цену эндпоинта, помогает реализовать интеграцию и отличает настройку от проверенного вызова и работающей функции. Сообщите ему свою цель и лимит расходов; не вставляйте ключ в чат.

Уже есть ключ или проект? Скажите об этом — начинать заново не нужно. Например: «У меня есть ключ SandBase. Добавь в этот проект поиск трафика через Similarweb; изучи API и сначала покажи стоимость живого теста». Ассистенту, который не может выполнять команды или загружать инструменты, нужен [путь настройки для конкретного клиента](/setup/).

[Передайте агенту Markdown-версию быстрого старта](https://www.sandbase.ai/quickstart.md) или используйте шаги ниже. Установка Skill настройки сама по себе не создаёт размещённый Agent.

### Дополнительно: запуск размещённого Agent в SandBase {#build-agent}

Выберите этот вариант, если работа состоит из нескольких шагов или должна использоваться повторно.

1. Откройте [Build → Agents](https://www.sandbase.ai/console/agents){target="_blank"} и выберите **Create**.
2. Заполните **Overview** и **Instructions**.
3. Выберите **Model**.
4. Добавьте Skills и MCP-инструменты в разделе **Capabilities**, затем задайте **Runtime**.
5. Выберите **Create & Chat**, чтобы протестировать Agent в сессии.
6. Вызывайте протестированную версию из своего приложения, используя вкладку **API** у Agent.

Подробнее: [Build Agent](/agents/). Как сделать то же самое из кода с официальным OpenAI SDK, см. в разделе [Совместимость с OpenAI](/agents/openai-compatibility).

## Skills, Tools и другие способы разработки {#skills-and-tools}

Выберите ресурс, подходящий для вашей задачи. Чтобы использовать API, не нужно устанавливать Skill или создавать размещённый Agent.

- **[Tools](https://www.sandbase.ai/tools):** выполнение конкретной задачи в готовом интерфейсе, например форматирование текста или поиск публичных данных.
- **[Skills](https://www.sandbase.ai/skills):** многократно используемый процесс для агента с инструкциями, скриптами и примерами.
- **Модели и API:** вызов возможности из Playground, вашего кода или подключённого агента. Посмотрите [языковые модели](https://www.sandbase.ai/models), [изображения и видео](https://www.sandbase.ai/models/image-video) или [API данных](https://www.sandbase.ai/apis).
- **[Размещённые Agents](/agents/):** настройка и запуск многократно используемого агента в SandBase.
- **[Sandboxes](/sandbox/):** изолированная среда для выполнения кода и работы с файлами.

### Использование Tool {#use-tools}

1. Откройте [Tools](https://www.sandbase.ai/tools) и выберите задачу, которую хотите выполнить.
2. Изучите требования инструмента к входным данным и метку цены или квоты. Бесплатные утилиты могут работать без аккаунта; для запуска инструментов данных нужен вход в SandBase, а для тестов моделей может потребоваться собственный ключ.
3. Введите запрошенный текст, URL, файл или другие данные и запустите инструмент.
4. Проверьте результат и при наличии воспользуйтесь кнопкой копирования или скачивания. Если хотите автоматизировать ту же задачу для инструмента данных, используйте связанный с ним API и пример запроса.

**Бесплатная дневная квота общая для рабочего пространства**, а не отдельная для каждого инструмента. Перед запуском проверьте доступность и указанную цену; бесплатная утилита не делает вызов модели или API бесплатным.

### Использование Skill {#use-skills}

1. Откройте [Skills](https://www.sandbase.ai/skills), выберите процесс и изучите его примеры, обязательные входные данные и зависимости.
2. Выберите один из вариантов, доступных на странице этого Skill:
   - **Run online:** войдите в аккаунт и запустите размещённый пример, если он предлагается. Следите за ходом выполнения и откройте полученный результат или файлы. Проверьте указанный лимит; доступность и ограничения зависят от Skill.
   - **Install / Download:** войдите в аккаунт, чтобы скачать пакет, если это предлагается. Распакуйте пакет целиком в рабочую папку, затем следуйте его инструкциям по установке или попросите локального агента прочитать его `SKILL.md`.
3. Для локального использования укажите задачу, входные данные, желаемый результат и лимит расходов. Подключите SandBase [через агента](#use-in-ai-tool); если скриптам Skill нужен ключ, настройте его в среде выполнения, а не вставляйте в чат.
4. Проверьте фактический результат. Скачивание Skill или подключение агента ещё не означает, что процесс успешно выполнился.

**Skill настройки** SandBase подключает ваш клиент; Skills из каталога описывают отдельные процессы. Перед установкой проверьте зависимости каждого Skill и поддерживаемый клиент. Вызовы моделей и API, используемые локальным процессом, могут тарифицироваться.

Полное пошаговое руководство, включая папки входных данных и сохранённые результаты, см. в разделе [Локальное использование Skill](/guides/skills/local-use).

## Дополнительно: общее рабочее пространство команды {#create-organization}

API-ключи, использование и оплата принадлежат организации. Если вы оцениваете сервис в одиночку, оставайтесь в личном рабочем пространстве. Создайте команду, если ключи и расходы будут общими для нескольких человек.

| Рабочее пространство | Когда использовать |
|---|---|
| **Личное** | Создаётся автоматически при первом входе. Одно на пользователя. |
| **Командное** | Общие участники, ключи и баланс. Создайте его для компании или проекта. |

### Создание команды {#create-team}

1. Откройте [Create team](https://www.sandbase.ai/console/members?create=1){target="_blank"} или выберите **Create Team** в меню аккаунта в правом верхнем углу Console.
2. Введите **Team name** и выберите **Create team**.
3. Убедитесь, что в меню аккаунта эта команда теперь отображается как активное рабочее пространство.
4. На странице **Developer → Team** выберите **Add member**, введите **Account email** существующего аккаунта SandBase и выберите **Workspace role** (Member или Admin).

У приглашённого человека уже должен быть аккаунт SandBase. Если его нет, отправьте ему [эту страницу](/getting-started/quickstart), чтобы он сначала вошёл, а затем добавьте его.

Если вы состоите в нескольких организациях, переключайтесь между ними в меню аккаунта. Ключи и оплата относятся к **активной** организации. О ролях см. [Организации](/admin/organizations).

## Убедитесь, что всё работает {#confirm-it-works}

Вы готовы, если выполнены все условия:

- В меню аккаунта Console показана нужная организация.
- Вы прошли один из путей: вызов API, запуск на сайте, подключённый AI-инструмент или Agent.
- Один запрос выполнился успешно.

Если запрос завершился ошибкой, проверьте активную организацию, ключ и раздел [Ошибки](/guides/error-handling). Если в рабочем пространстве не осталось баланса, пополните его в [Billing](https://www.sandbase.ai/console/billing){target="_blank"}.

### Если что-то не получается {#if-you-get-stuck}

| Что вы видите | Что проверить |
| --- | --- |
| Требуется вход | Войдите, вернитесь на исходную страницу и проверьте активное рабочее пространство. |
| Недействительный ключ или отказ в доступе | Убедитесь, что ключ принадлежит нужному рабочему пространству и имеет доступ к эндпоинту. Пополнение баланса не исправляет права доступа. |
| Недостаточно средств или квота исчерпана | Прочитайте ответ: при проблеме с балансом проверьте Billing, при лимите квоты — указанное время сброса. |
| У агента нет инструментов | Начните новую сессию клиента и выполните диагностику из раздела [Подключение AI-инструментов](/setup/). |
| Задача всё ещё выполняется | Следите за возвращённым статусом задачи или индикатором прогресса на странице. Не отправляйте один и тот же платный запрос повторно. |
