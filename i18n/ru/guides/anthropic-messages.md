# Anthropic Messages {#anthropic-messages}

SandBase предоставляет совместимый с Anthropic эндпоинт `POST /v1/messages`. Приложения на Anthropic SDK можно подключить, заменив API-ключ и базовый URL.

```python
import os
from anthropic import Anthropic

client = Anthropic(
    api_key=os.environ["SANDBASE_API_KEY"],
    base_url="https://api.sandbase.ai",
)
```

## Заголовки аутентификации и версии {#authentication-and-version-headers}

Используйте `x-api-key` или `Authorization: Bearer …`. Если переданы оба, приоритет у `x-api-key`. Необязательный заголовок `anthropic-version` передаётся вышестоящему сервису; если он не указан, используется `2023-06-01`. Необязательные значения `anthropic-beta` тоже передаются, если это совместимо с провайдером.

## Сообщения и блоки содержимого {#messages-and-content-blocks}

Сообщения используют роли `user` и `assistant`. Системную инструкцию помещайте в поле верхнего уровня `system`. Содержимое может быть простым текстом или массивом типизированных блоков, таких как `text`, `image`, `tool_use` и `tool_result`.

## Инструменты и расширенное мышление {#tools-and-extended-thinking}

Добавляйте определения инструментов в `tools` и управляйте их выбором через `tool_choice`. Если выбранная модель поддерживает расширенные рассуждения, настройте их через `thinking`; при продолжении диалога сохраняйте возвращённые блоки thinking.

## Потоковая передача {#streaming}

Задайте `stream: true`, чтобы получать SSE-события в стиле Anthropic, включая `message_start`, события блоков содержимого, `message_delta` и `message_stop`. SandBase также пересылает keepalive и beta-события, определённые провайдером. Для прямой совместимости клиентам следует игнорировать неизвестные типы событий и обрабатывать события `error` на уровне протокола.

## Совместимость {#compatibility}

SandBase сопоставляет публичное имя модели с выбранным провайдером. Остальные совместимые поля запроса и байты ответа сохраняются, если у провайдера нет явного правила совместимости, которое удаляет неподдерживаемое поле или отклоняет кандидата. Beta-функции конкретных провайдеров могут быть доступны не для всех моделей. Полную схему запроса и ответа см. в разделе [Создание Anthropic Message](/api-reference/anthropic-compat).
