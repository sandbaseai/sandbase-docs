# Account API {#account-api}

Эндпоинты аккаунта доступны только для чтения и работают с организацией, определяемой по Bearer API-ключу.

| Операция | Эндпоинт |
|---|---|
| [Получить баланс](./balance) | `GET /v1/account/balance` |
| [Список истории выполнения](./history) | `GET /v1/account/history` |

Значения баланса и стоимости — точные десятичные строки. Храните их как десятичные значения и не преобразуйте через
двоичную арифметику с плавающей точкой.

История выполнения предназначена для оперативного просмотра недавних операций. Для долгосрочной финансовой
сверки используйте записи биллинга или выгрузки.

Фильтрация истории использует необработанные метки времени UTC. Без `request_id` необязательный параметр совместимости `timezone` проверяется как имя часового пояса IANA, но не преобразует метки времени в ответе; в режиме точного `request_id` он игнорируется вместе с остальными фильтрами. Неизвестные значения `type` не применяют фильтр по типу выполнения; для работающего фильтра используйте `multimodal`, `llm` или `api`. Неподдерживаемые значения `range` заменяются на `7d`.

Записи истории могут содержать сохранённые параметры запросов и вывод моделей. Ограничьте доступ к API-ключу соответственно
и не копируйте ответы истории в логи или обращения в поддержку, не проверив их на конфиденциальные данные.
