# Media Assets API {#media-assets-api}

Используйте совместимый с официальным протокол Asset на `/v1/assets`, чтобы регистрировать URL медиафайлов и получать `asset_url` для
нативных запросов генерации видео.

Сквозной пример, в котором медиафайл регистрируется, а возвращённая ссылка `asset://` используется с Seedance, см. в разделе
[Использование зарегистрированных медиа-Assets](/api-reference/volcengine-contents-generations#use-registered-media-assets) справочника Seedance.

## Обзор {#overview}

| Метод | Путь | Описание |
|--------|------|-------------|
| `POST` | `/v1/assets` | Зарегистрировать Asset |
| `GET` | `/v1/assets/{id}` | Получить метаданные Asset и текущий URL для скачивания |

## POST /v1/assets {#post-v1-assets}

Регистрирует публично доступный URL файла в библиотеке ассетов и возвращает `asset_url`, на который можно ссылаться в запросах генерации видео.

### Запрос {#request}

```http
POST /v1/assets
Authorization: Bearer $SANDBASE_API_KEY
Content-Type: application/json
```

```json
{
  "url": "https://example.com/tea-ad.mp4",
  "asset_type": "Video",
  "name": "Tea ad reference video"
}
```

| Поле | Тип | Обязательное | Описание |
|-------|------|----------|--------------|
| `url` | string | Да | Публично доступный URL файла |
| `asset_type` | string | Да | Тип ассета: `Image` / `Video` / `Audio` (с учётом регистра) |
| `name` | string | Нет | Необязательное имя ассета |

### Ответ {#response}

```json
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "asset_url": "asset://asset-20260710150403-hx4hf",
  "asset_type": "Video",
  "name": "Tea ad reference video",
  "created_at": "2026-07-10T15:04:03Z"
}
```

| Поле | Описание |
|-------|--------------|
| `id` | Внутренний ID записи |
| `asset_url` | Адрес-ссылка для запросов генерации видео |
| `asset_type` | Тип ассета |
| `name` | Имя ассета |
| `created_at` | Метка времени создания |

### Использование asset_url {#using-asset-url}

После регистрации передайте `asset_url` во входное поле, которое принимает ссылку на Asset в актуальной схеме выбранной модели. Имена полей зависят от модели, например:

```json
{
  "type": "video_url",
  "video_url": {"url": "asset://asset-20260710150403-hx4hf"},
  "role": "reference_video"
}
```

### Ошибки {#errors}

| HTTP-статус | Описание |
|-------------|--------------|
| 400 | Отсутствует обязательное поле или указан недопустимый `asset_type` |
| 502 | Ошибка регистрации ассета у вышестоящего провайдера |
| 500 | Нет доступных учётных данных или внутренняя ошибка |

## GET /v1/assets/{id}

Возвращает подписанный URL для скачивания зарегистрированного ассета по его внешнему ID. Используется для предпросмотра или скачивания исходного файла.

### Запрос {#request-1}

```http
GET /v1/assets/asset-20260710150403-hx4hf
Authorization: Bearer $SANDBASE_API_KEY
```

| Параметр | Расположение | Описание |
|-----------|----------|--------------|
| `id` | path | Внешний ID (часть `asset_url` после `asset://`) |

### Ответ {#response-1}

```json
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "external_id": "asset-20260710150403-hx4hf",
  "asset_url": "asset://asset-20260710150403-hx4hf",
  "status": "Active",
  "asset_type": "Video",
  "name": "Tea ad reference video",
  "download_url": "https://cdn.example.com/...?X-Tos-Expires=43200",
  "created_at": "2026-07-10T15:04:03Z"
}
```

| Поле | Описание |
|-------|--------------|
| `asset_url` | Адрес-ссылка для генерации видео (постоянный) |
| `status` | Статус жизненного цикла Asset, сообщаемый провайдером. Считайте его открытой строкой. |
| `download_url` | URL для скачивания, возвращённый провайдером; может быть пустым, пока Asset не готов |

### Ошибки {#errors-1}

| HTTP-статус | Описание |
|-------------|--------------|
| 404 | Asset не найден или не принадлежит вашей организации |
| 502 | Ошибка запроса к вышестоящему провайдеру |

## Примечания {#notes}

::: tip Важно
- `asset_url` имеет формат `asset://{external_id}` и является многократно используемой ссылкой для передачи в поддерживаемые входы моделей
- Считайте `download_url` управляемым провайдером. Если он пуст или перестал работать, снова вызовите этот эндпоинт, чтобы получить актуальное значение
- `asset_type` чувствителен к регистру: `Image` / `Video` / `Audio`
- Передаваемый URL должен быть публично доступен (платформа должна иметь возможность его загрузить)
:::
