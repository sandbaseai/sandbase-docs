# Sandbox Playground {#sandbox-playground}

Попробуйте Sandbox API со своим ключом. Операции подключаются к **sandbox.sandbase.ai** и могут тарифицироваться.

  <SandboxPlayground />
</ClientOnly>

## Ваш ключ остаётся под вашим контролем {#your-key-stays-under-your-control}

- **Только в памяти страницы.** Этот Playground не сохраняет ваш API-ключ и токены подключения в хранилище браузера или cookie, не помещает их в URL и не записывает в журнал активности страницы или примеры запросов.
- **Очистка в любой момент.** Выберите **Clear key**, чтобы удалить ключ, токены подключения и отображаемую активность, даже если запрос ещё выполняется. Обновление страницы или уход с неё также их очищает. Чтобы переподключиться, нужно будет снова ввести ключ.
- **Используется только для ваших запросов.** Ключ передаётся в SandBase для аутентификации запрошенных вами операций Sandbox. Очистка страницы не отзывает ключ; при необходимости отзовите его в разделе [Developer → API Keys](https://www.sandbase.ai/console/keys).

Эти гарантии касаются только того, как этот Playground обращается с учётными данными. Они не означают, что активность Sandbox или записи об использовании на стороне сервиса удаляются. Не вводите секреты в команды или файлы: их содержимое может остаться в вашей песочнице.

## Очищайте ресурсы отдельно {#clean-up-resources-separately}

Очистка ключа не отменяет операцию, уже полученную сервисом, и не удаляет песочницу. Удаляйте экземпляры после завершения работы. Если результат создания неизвестен, проверьте свои экземпляры, прежде чем создавать новый. Перед очисткой страницы сохраните ID экземпляров, которые понадобятся для очистки.
