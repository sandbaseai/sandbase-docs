# Документация SandBase {#sandbase-docs}

Работайте с моделями и API напрямую или определяйте повторно используемые Agents, которые выполняются на управляемой инфраструктуре.

SandBase предлагает два взаимодополняющих способа создания AI-приложений. Начните с самого простого варианта, подходящего для задачи; по мере роста приложения их можно сочетать.

## Выберите способ разработки {#choose-how-to-build}

| | Модели и API | Управляемые Agents |
|---|---|---|
| **Что это** | Прямой доступ к языковым моделям, моделям изображений, видео и аудио, а также к сторонним API | Повторно используемые версионируемые конфигурации Agent, которые выполняет SandBase |
| **Лучше всего подходит для** | Собственных циклов приложения и детального управления запросами | Многошаговой, асинхронной или повторяющейся работы |
| **Чем управляете вы** | Промпты, оркестрация, повторные попытки и состояние приложения | Определение Agent, включённые возможности, входные данные и способ доставки результата |
| **С чего начать** | [Модели и API](https://www.sandbase.ai/models) | [Build Agent](/agents/) |

::: tip Один API-ключ SandBase
Один и тот же API-ключ позволяет вызывать модели, API и Agents. Храните ключи на сервере и никогда не раскрывайте их в браузерном коде.
:::

## Основные понятия {#core-concepts}

### Модели и API {#models-and-apis}

Используйте модели для задач с текстом, изображениями, видео и аудио. Используйте API, когда приложению нужны внешние данные или действия. Каталог на сайте SandBase показывает доступные возможности, цены, схемы входных данных и рабочие примеры.

- [Каталог моделей](https://www.sandbase.ai/models)
- [Каталог API](https://www.sandbase.ai/apis)
- [Первый вызов API](/getting-started/first-call)
- [Справочник API](/api-reference/)

### Agents {#agents}

Agent — это повторно используемая версионируемая конфигурация, включающая модель, инструкции, Skills и MCP-подключения. Определите его один раз, а затем запускайте в сессиях.

- [Что такое Agents](/agents/)
- [Определение Agent](/agents/agent-api)
- [Добавление Skills и MCP-инструментов](/agents/mcp-tools)

### Сессии {#sessions}
Сессия запускает одну версию Agent. Создайте её через `POST /v1/agents/sessions`, отправьте ввод, получайте события в потоке и затем прочитайте весь диалог.

- [Руководство по сессиям](/agents/sessions)
- [Sessions API](/api-reference/sessions/)

## Первые шаги {#first-steps}

1. Создайте организацию и [API-ключ](/getting-started/api-keys).
2. Выберите модель, API или Agent в [каталоге](https://www.sandbase.ai/models).
3. Выполните прямой запрос или определите и протестируйте Agent.
4. Запускайте протестированный Agent в сессиях из своего приложения.
5. Просматривайте сессии, ошибки, задержки и расходы в Console.
