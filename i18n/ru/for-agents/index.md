# Обзор API для ИИ {#ai-friendly-api-overview}

::: info Контракт сессии
Сессия (`ses_*`) выполняет одну сохранённую версию Agent; создаётся напрямую через `POST /v1/agents/sessions`. Экземпляры среды выполнения остаются внутренними и никогда не возвращаются.
:::

> Краткий справочник и для людей, и для ИИ-агентов. Текстовые версии, оптимизированные для загрузки в LLM, см. в [`llms.txt`](https://www.sandbase.ai/docs/llms.txt).

## Что такое SandBase? {#what-is-sandbase}

SandBase — инфраструктурная платформа для ИИ-агентов. Один API-ключ даёт доступ к включённым моделям и API для текста, изображений, видео, аудио, поиска и данных, а также к процессам Agent. Получайте актуальный каталог через discovery, а не полагайтесь на фиксированное количество.

## Базовый URL API {#api-base-url}

```
https://api.sandbase.ai/v1
```

## Аутентификация {#authentication}

Все запросы требуют Bearer-токен:

```
Authorization: Bearer sk-YOUR_KEY
```

Ключ можно получить в разделе [Developer → API Keys](https://www.sandbase.ai/console/keys).

## Быстрый пример {#quick-example}

```bash
curl https://api.sandbase.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-5.6-luna",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## Основные API {#core-apis}

| Метод | Маршрут | Описание |
|--------|----------|-------------|
| `POST` | `/v1/chat/completions` | OpenAI-совместимый чат; дополнительные возможности зависят от выбранной модели |
| `POST` | `/v1/messages` | Anthropic-совместимый API сообщений |
| `POST` | `/v1/run` | Отправка генерации модели по схеме конкретной модели |
| `GET` | `/v1/run/{id}` | Опрос статуса асинхронной генерации и получение результатов |
| `GET` | `/v1/models` | Список включённых логических моделей; по умолчанию тип LLM |
| `GET` | `/v1/models/{id_or_name}` | Сведения о модели, схема, возможности и цены |
| `GET` | `/v1/tasks/{task_id}/cost` | Стоимость и использование задачи |

## Дополнительные группы API {#additional-api-groups}

Помимо основных API генерации, SandBase предоставляет API для управления жизненным циклом агентов. Типовые сценарии см. в [Руководстве по API для ИИ](./full), а полный контракт — в [спецификации OpenAPI](https://www.sandbase.ai/docs/openapi.yaml).

| Группа | Основные маршруты | Назначение |
|-------|---------------|---------|
| **Agents** | `POST /v1/agents`, `GET /v1/agents`, `POST /v1/agents/{agent_id}` | Создание и версионирование сохранённых определений Agent |
| **Сессии** | `POST /v1/agents/sessions`, `POST /v1/agents/sessions/{session_id}/events`, `GET /v1/agents/sessions/{session_id}/events` | Запуск Agent, отправка ввода и поток событий в реальном времени |
| **Skills** | `POST /v1/skills`, `GET /v1/skills` | Версионируемые пакеты инструкций, которые подключают Agents |
| **MCP-подключения и Secrets** | `POST /v1/mcp-connections`, `POST /v1/secrets` | Удалённые MCP-инструменты по HTTPS и их Bearer-токены только для записи |

Ресурсы платформы Agents принимают `Authorization: Bearer` или `X-API-Key` и при ошибке возвращают `{"error":{"type","code","param","message"}}`.

## Модель ценообразования {#pricing-model}

Оплата по факту использования. Цены зависят от модели и могут меняться независимо от этой страницы:

- **Цены моделей**: актуальную формулу и единицы выбранной модели читайте в `model_card`
- **Цены за токены**: могут включать компоненты для ввода, вывода, кэша или рассуждений, если модель их объявляет
- **Медиа и другие операции**: могут тарифицироваться за запрос, длительность, разрешение или в других единицах конкретной модели
- **API данных** (поиск, соцсети, скрейпинг, электронная коммерция, финансы): каждая организация получает 100 бесплатных вызовов в сутки по UTC, общих для всех подходящих API данных; после этого вызовы оплачиваются поштучно, а не блокируются. В MCP подходящие инструменты показывают `pricing.free_quota` в `sandbase_inspect`, а `sandbase_account` возвращает `free_api_quota` (`daily_limit`, `used_today`, `remaining`, `resets_at`). См. [Ежедневные бесплатные вызовы API](/guides/billing#daily-free-api-calls).

Узнайте актуальный ID модели через `GET /v1/models`, затем перед отправкой запроса изучите `GET /v1/models/{id_or_name}`. Не предполагайте, что цены или скидки на кэш одинаковы у разных провайдеров.

Если операция возвращает ID задачи, проверьте её записанную стоимость:

```bash
curl https://api.sandbase.ai/v1/tasks/{task_id}/cost \
  -H "Authorization: Bearer sk-YOUR_KEY"
```

## Ограничения частоты запросов {#rate-limits}

Опубликованного универсального числового значения по умолчанию нет. На запросы может действовать необязательный лимит запросов в минуту,
назначенный вашей организации и общий для всех её API-ключей. Ответ `429` не содержит заголовков квоты или `Retry-After`; используйте ограниченную
экспоненциальную задержку со случайным разбросом. См. [Руководство по ошибкам](./errors).
