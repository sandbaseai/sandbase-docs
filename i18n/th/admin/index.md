# บัญชีและการเรียกเก็บเงิน {#account-and-billing}

การตั้งค่าองค์กรของคุณใช้กำหนดว่าใครเป็นเจ้าของการใช้งาน แอปพลิเคชันยืนยันตัวตนอย่างไร และติดตามการใช้จ่ายอย่างไร

## สิ่งที่คุณจัดการได้ {#what-you-manage}

| ส่วน | ใช้สำหรับ |
|---|---|
| [องค์กร](/admin/organizations) | จัดการขอบเขตของเวิร์กสเปซ สมาชิก และความเป็นเจ้าของ |
| [API Keys](/getting-started/api-keys) | สร้าง หมุนเวียน และเพิกถอนข้อมูลรับรองของแอปพลิเคชัน |
| [การเรียกเก็บเงินและเครดิต](/admin/billing) | ตรวจสอบยอดคงเหลือ ซื้อเครดิต ตั้งค่าการเติมเงินอัตโนมัติ และตรวจสอบการใช้งานใน Activities และ Analysis |
| [ราคาและการใช้งาน](/guides/billing) | ดูราคาโมเดล จำนวนการเรียก API ฟรีรายวัน และค่าใช้จ่ายของงานหนึ่งงาน |
| [ขีดจำกัดอัตรา](/guides/rate-limiting) | ทำความเข้าใจขีดจำกัดคำขอและวิธีลองใหม่อย่างปลอดภัย |

## การตั้งค่าที่แนะนำ {#recommended-setup}

1. ตรวจสอบให้แน่ใจว่าคุณกำลังทำงานในองค์กรที่ถูกต้อง
2. สร้าง API key แยกกันสำหรับ development, staging และ production
3. ตั้งชื่อคีย์ตามแอปพลิเคชันและสภาพแวดล้อมที่ใช้
4. ตรวจสอบ Activities และการเรียกเก็บเงินหลังจากส่งคำขอ production ครั้งแรก
5. เพิกถอนคีย์ที่ไม่ได้ใช้ และตรวจสอบการใช้งานที่ผิดปกติโดยเร็ว

## ความเป็นเจ้าของและสิทธิ์การเข้าถึง {#ownership-and-access}

API key และการใช้งานเป็นขององค์กร การสลับองค์กรจะเปลี่ยนทรัพยากร คีย์ และบริบทการเรียกเก็บเงินที่แสดงใน Console ก่อนเปลี่ยนการกำหนดค่า production ให้ตรวจสอบองค์กรที่เลือกไว้ และประสานงานการหมุนเวียนคีย์กับแอปพลิเคชันที่ใช้คีย์นั้น

## หลักความปลอดภัยเบื้องต้น {#security-basics}

- เก็บคีย์ไว้ในตัวแปรสภาพแวดล้อมหรือระบบจัดการความลับ (secrets manager)
- ห้ามวางคีย์ลงในคำสั่งของ Agent, ซอร์สโค้ด, ภาพหน้าจอ หรือข้อความถึงฝ่ายสนับสนุน
- ใช้คีย์แยกกันสำหรับแต่ละแอปพลิเคชันและสภาพแวดล้อม
- เพิกถอนคีย์ทันทีหากคีย์อาจรั่วไหล
- ติดตาม Activities เพื่อหาปริมาณการใช้งาน โมเดล หรือ endpoint ที่ผิดปกติ
