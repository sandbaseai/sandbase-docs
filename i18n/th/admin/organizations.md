# องค์กร {#organizations}

องค์กรเป็นหน่วยของการเรียกเก็บเงินและการควบคุมสิทธิ์เข้าถึงใน SandBase โดย API key, ยอดเงินคงเหลือ, การใช้งาน และสมาชิกทั้งหมดจะเป็นขององค์กร

## ประเภทองค์กร {#organization-types}

| ประเภท | คำอธิบาย |
|------|-------------|
| **ส่วนตัว** | สร้างให้อัตโนมัติเมื่อเข้าสู่ระบบครั้งแรก ผู้ใช้หนึ่งคนมีได้หนึ่งองค์กร |
| **ทีม** | สร้างเอง มีสมาชิกได้หลายคนพร้อมบทบาท |

## บทบาทของสมาชิก {#member-roles}

| บทบาท | สิทธิ์ |
|------|-------------|
| **Owner** | เข้าถึง workspace ได้ทั้งหมด รวมถึงเปลี่ยนบทบาทของสมาชิก |
| **Admin** | จัดการคีย์และการเรียกเก็บเงิน รวมถึงเพิ่มหรือนำสมาชิกที่ไม่ใช่ Owner ออก |
| **Member** | ใช้งาน workspace และ API key ของ workspace ได้ แต่ไม่มีสิทธิ์จัดการสมาชิก |

## สร้างองค์กรแบบทีม {#create-a-team-organization}

1. เปิดเมนูบัญชีที่มุมขวาบนของ Console
2. เลือก **Create Team** หรือเปิด **Developer → Team** แล้วเลือก **Create team**
3. กรอก **Team name** แล้วเลือก **Create team**
4. เลือก **Add member** กรอก **Account email** ของบัญชี SandBase ที่มีอยู่แล้ว และเลือก **Workspace role**: **Member** หรือ **Admin**

สมาชิกที่เพิ่มเข้ามาต้องมีบัญชี SandBase อยู่แล้ว Owner สามารถเปลี่ยนบทบาทของสมาชิกได้ ส่วน Owner และ Admin สามารถนำ
สมาชิกที่ไม่ใช่ Owner ออกได้

## สลับองค์กร {#switch-organizations}

หากคุณเป็นสมาชิกของหลายองค์กร ให้สลับองค์กรได้จากเมนูบัญชี หรือใช้แถบ **Switch workspace** ในหน้า **Developer → Team** API key และการเรียกเก็บเงินจะอยู่ในขอบเขตขององค์กรที่ใช้งานอยู่

## ยอดเงินคงเหลือและการเรียกเก็บเงิน {#balance-and-billing}

แต่ละองค์กรมียอดเงินคงเหลือของตัวเอง การเรียกโมเดล การเรียก API, Agent Session และงานรันไทม์จะถูกหักจากยอดเงินนี้ ดูรายละเอียดได้ที่ [การเรียกเก็บเงิน](/admin/billing)
