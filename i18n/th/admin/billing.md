# การเรียกเก็บเงินและเครดิต {#billing-and-credits}

หน้านี้อธิบายการจัดการการเรียกเก็บเงินใน [SandBase Console](https://www.sandbase.ai/console) สำหรับอัตราค่าบริการและการลดค่าใช้จ่าย ดูที่[ราคา](/guides/billing)

SandBase เรียกเก็บค่าใช้จ่ายของงานที่รองรับจากยอดคงเหลือขององค์กร ราคาปัจจุบัน ข้อเสนอ ผู้ให้บริการชำระเงิน
ยอดเติมเงินขั้นต่ำ และความพร้อมให้บริการในแต่ละภูมิภาคจะแสดงใน Console และอาจเปลี่ยนแปลงได้โดยไม่ขึ้นกับ
คู่มือนี้

## ยอดคงเหลือ {#balance}

เปิด [Developer → Billing](https://www.sandbase.ai/console/billing) หน้า **Credits** จะแสดงข้อมูลขององค์กรที่ใช้งานอยู่ดังนี้

| รายการ | ความหมาย |
|------|---------------|
| **Available balance** | ยอดที่พร้อมใช้กับ Models และ APIs |
| **Credit limit** | วงเงินการใช้จ่ายของ workspace |
| **Current level** | ระดับบัญชีและจำนวนงานที่ทำพร้อมกันได้ |

ยอดคงเหลือเดียวกันจะแสดงบนการ์ด **Balance** ใน Console Dashboard และในส่วนหัวของเว็บไซต์เมื่อคุณลงชื่อเข้าใช้
ให้ถือว่า Console เป็นแหล่งข้อมูลหลักสำหรับโปรโมชันและเงื่อนไขการชำระเงิน และอย่าทำคำขอเครือข่ายภายในของ Console
แบบอัตโนมัติ

## ซื้อเครดิต {#buy-credits}

1. เปิด [Billing](https://www.sandbase.ai/console/billing) และตรวจสอบว่า **Credits go to** แสดง workspace ที่คุณต้องการเติมเงิน
2. ใต้ **Buy credits** ให้เลือกจำนวนเงินที่กำหนดไว้ หรือกรอก **Custom amount** เป็น USD ยอดเติมเงินขั้นต่ำจะแสดงอยู่บนหน้า
3. หากมี **Payment provider** ให้เลือกมากกว่าหนึ่งราย ให้เลือก **Stripe** (บัตรและวอลเล็ตทั่วโลก) หรือ **Airwallex** (บัตรและวิธีชำระเงินท้องถิ่น)
4. ตรวจสอบ **Pay**, **Bonus** และ **Receive** ในตัวอย่าง จากนั้นเลือก **Continue with Stripe** (หรือผู้ให้บริการที่คุณเลือก) และชำระเงินให้เสร็จในหน้าชำระเงินของผู้ให้บริการ
5. ยืนยันยอดคงเหลือที่อัปเดตแล้วใต้ **Credit transactions** ก่อนเริ่มงานที่อ่อนไหวต่อค่าใช้จ่าย

SandBase ไม่จัดเก็บรายละเอียดบัตร หน้าชำระเงินโฮสต์โดยผู้ให้บริการ

### โบนัสการเติมเงินครั้งแรก {#first-top-up-bonus}

เมื่อบัญชีและ workspace ยังไม่เคยเติมเงินมาก่อน **Current offers** จะแสดงโบนัสการเติมเงินครั้งแรก โดยหน้าจะระบุ
เปอร์เซ็นต์โบนัสและเพดานสูงสุด โบนัสใช้ได้หนึ่งครั้งต่อบัญชีและต่อ workspace และการคืนเงินจะเรียกคืนโบนัส
ตามสัดส่วน โบนัสจะแสดงเป็นแถวแยกใน **Credit transactions**

## เติมเงินอัตโนมัติ {#auto-top-up}

**Auto Top-up** จะเติมยอดคงเหลือด้วยบัตรที่บันทึกไว้เมื่อยอดลดลงต่ำกว่าเกณฑ์ ปัจจุบันรองรับเฉพาะ Stripe
และมีเพียงเจ้าของและผู้ดูแล workspace เท่านั้นที่จัดการได้

1. ใต้ **Payment cards** ให้เลือก **Add Card** และบันทึกบัตรใน Stripe
2. เลือก **Turn on auto top-up** จากนั้นตั้งค่า **When balance goes below**, **Top-up amount**, **Monthly limit** (ไม่บังคับ) และบัตร
3. เลือก **I authorize these automatic charges** แล้วยืนยัน

เมื่อถึงขีดจำกัดรายเดือนแล้ว การเติมเงินอัตโนมัติจะหยุดจนสิ้นเดือนปฏิทินนั้น (UTC) การเรียกเก็บเงินอัตโนมัติ
จะแสดงใน **Credit transactions** พร้อมช่องทาง `Auto top-up · Stripe`

## แลกคูปอง {#redeem-a-coupon}

กรอก **Coupon code** ใต้ **Redeem a coupon** แล้วเลือก **Redeem credit** คูปองจะใช้กับ workspace ที่ใช้งานอยู่
เท่านั้น ดังนั้นให้ตรวจสอบองค์กรที่เลือกก่อน

## การควบคุมการใช้จ่าย {#spending-controls}

| การควบคุม | ขอบเขต | พฤติกรรม |
|---------|-------|----------|
| ขอบเขตเงินทุนขององค์กร | ทั้งองค์กร | ยอดคงเหลือที่ใช้ได้รวมกับวงเงินเครดิตที่กำหนดไว้ คำขอที่ไม่มีเงินทุนเพียงพออาจได้ HTTP 402 |
| ขีดจำกัดการใช้จ่ายของคีย์ | ต่อ API key | เพดานต่อคีย์ (ไม่บังคับ) โดยไม่เกินยอดคงเหลือขององค์กร |
| ขีดจำกัดรายเดือนของการเติมเงินอัตโนมัติ | ทั้งองค์กร | จำกัดการเรียกเก็บเงินอัตโนมัติต่อเดือนปฏิทิน (UTC) |

หากต้องการตั้งขีดจำกัดการใช้จ่ายต่อคีย์ ดูที่ [API Keys](/getting-started/api-keys)

## Activities และ Analysis {#activities-and-analysis}

[Developer → Activities](https://www.sandbase.ai/console/activities) มีสองแท็บ:

- **Request History** แสดงรายการคำขอแต่ละรายการพร้อม API key, โมเดล, สถานะ, latency และค่าใช้จ่าย
- **Usage** แสดงคำขอและค่าใช้จ่ายในช่วง 7 หรือ 30 วัน, **Model APIs by Archived Spend** และ **Billing Records** ทั้งสองตารางมี **Export CSV** ไฟล์ส่งออกของ billing records มีคอลัมน์ **Free Quota** ที่ระบุการเรียกที่อยู่ในโควตาฟรีรายวัน

[Developer → Analysis](https://www.sandbase.ai/console/analytics) เพิ่ม **Overview**, **Cost analysis** และ
**Health diagnostics** สำหรับ 7 หรือ 30 วัน UTC ล่าสุดที่ครบวัน

สำหรับราคาสาธารณะและสัญญาค่าใช้จ่ายของงาน ดูที่[ราคาและการใช้งาน](/guides/billing) และ
[ดูค่าใช้จ่ายของงาน](/api-reference/tasks/cost)
