# เริ่มต้นใช้งานอย่างรวดเร็ว {#quick-start}

## เลือกวิธีที่คุณต้องการใช้ SandBase {#connect}

นี่คือ **สามทางเลือกในการเริ่มต้น** ไม่ใช่สามขั้นตอนที่ต้องทำให้ครบ ใช้บัญชีและ workspace ของ SandBase เดียวกันได้ในทุกทางเลือก

<QuickstartPaths />

ต้องการแค่งานสำเร็จรูปใช่ไหม [สำรวจ Tools](#use-tools) หรือ[เลือก Skill](#use-skills) คุณเรียกดูแคตตาล็อกสาธารณะและเอกสารได้ก่อนลงชื่อเข้าใช้

### เริ่มจากรีโพสิทอรีโอเพนซอร์ส {#start-from-the-open-source-repositories}

- **[SandBase — SDK และตัวอย่าง](https://github.com/sandbaseai/sandbase)**: ไคลเอนต์ Python, TypeScript และ Go ตัวอย่าง API และเวิร์กโฟลว์ของ Agent ที่โฮสต์ไว้ ใช้เมื่อสร้างแอปพลิเคชันของคุณเอง
- **[SandBase CLI และ MCP](https://github.com/sandbaseai/cli)**: ติดตั้งและเชื่อมต่อเครื่องมือ AI ของคุณ หรือค้นหาและรันความสามารถจากเทอร์มินัล ใช้กับ Agent ที่คุณมีอยู่แล้ว

## ก่อนเริ่ม: ลงชื่อเข้าใช้ {#create-account}

ลงชื่อเข้าใช้ก่อนใช้ Playground รัน Skill ที่โฮสต์ไว้ หรือสร้าง API key เครื่องมือฟรีที่ใช้ได้โดยไม่ต้องมีบัญชีสามารถใช้ได้ทันที **ลงชื่อเข้าใช้แล้วใช่ไหม ข้ามขั้นตอนนี้ได้เลย** แล้วตรวจสอบว่าเมนูบัญชีแสดง workspace ที่คุณต้องการใช้

SandBase ใช้ GitHub หรือ Google ไม่มีการสมัครด้วยอีเมลและรหัสผ่านแยกต่างหาก

1. เปิด[สร้างบัญชี / ลงชื่อเข้าใช้](https://www.sandbase.ai/login){target="_blank"}
2. ทำการตรวจสอบความปลอดภัยให้เสร็จ แล้วเลือก **Sign in with GitHub** หรือ **Sign in with Google**
3. อนุมัติการเข้าถึงในหน้าต่างของผู้ให้บริการ
4. กลับไปยังหน้าที่คุณใช้อยู่ หรือเปิด [Console](https://www.sandbase.ai/console){target="_blank"}

การเข้าสู่ระบบครั้งแรกจะสร้างบัญชีและ **workspace ส่วนตัว** ให้คุณ คุณไม่จำเป็นต้องสร้างองค์กรก่อนลองใช้ SandBase

หากมีเครดิตต้อนรับปรากฏขึ้น คุณเริ่มใช้งานได้โดยไม่ต้องเพิ่มวิธีการชำระเงิน การ์ด **Balance** บน Console Dashboard และ [Billing](https://www.sandbase.ai/console/billing){target="_blank"} จะแสดงยอดเงินคงเหลือปัจจุบัน

## บนแพลตฟอร์ม {#use-on-website}

เลือกวิธีนี้หากต้องการลองใช้ Model, API หรือ Agent ในเบราว์เซอร์ก่อน โดยไม่ต้องติดตั้งไคลเอนต์และไม่ต้องเขียนโค้ด

1. ลงชื่อเข้าใช้ แล้วเปิดแคตตาล็อก:
   - [โมเดลภาษา](https://www.sandbase.ai/models){target="_blank"}
   - [โมเดลภาพและวิดีโอ](https://www.sandbase.ai/models/image-video){target="_blank"}
   - [APIs](https://www.sandbase.ai/apis){target="_blank"}
   - [Agents](https://www.sandbase.ai/agents){target="_blank"}
2. เปิดหน้ารายละเอียดของโมเดลหรือ API แล้วเลือก **Playground** หากมี
3. ป้อน input ที่จำเป็น เช่น prompt ภาพ คำค้นหา หรือ URL ตรวจสอบราคาที่แสดงก่อนรัน
4. รันคำขอแล้วดูข้อความ ข้อมูล ภาพ วิดีโอ หรือสถานะงานที่ส่งคืน

คุณไม่ต้องสร้าง API key แยกสำหรับ Playground บนเว็บไซต์ หากความสามารถใดไม่มี Playground ให้ใช้แท็บ **API** ของความสามารถนั้นและทำตามเส้นทาง API ด้านล่าง

## ผ่าน API {#call-api}

เลือกวิธีนี้หากคุณกำลังเพิ่มความสามารถหนึ่งอย่างลงในแอปของคุณ

1. ใช้คีย์ที่ถูกต้องของ workspace ที่ต้องการซ้ำ หรือสร้าง [API key](/getting-started/api-keys) ใน [Developer → API Keys](https://www.sandbase.ai/console/keys){target="_blank"} ด้วย **New key** คัดลอกทันที เพราะคีย์จะแสดงเพียงครั้งเดียว
2. กรองแคตตาล็อกแล้วเปิดหน้ารายละเอียด:
   - [โมเดลภาษา](https://www.sandbase.ai/models){target="_blank"} — กรองตามผู้ให้บริการ ความสามารถ บริบท และราคา
   - [โมเดลภาพและวิดีโอ](https://www.sandbase.ai/models/image-video){target="_blank"} — กรองโมเดลมัลติโมดัล เช่น text-to-image, image-to-image, text-to-video และ image-to-video
   - [APIs](https://www.sandbase.ai/apis){target="_blank"} — กรองทรัพยากร API ตามแพลตฟอร์มและแหล่งข้อมูล
3. เปิดแท็บ **API** คัดลอกคำขอตัวอย่าง แล้วกรอกฟิลด์ที่จำเป็นของเอนด์พอยต์นั้น
4. เก็บคีย์ SandBase ของคุณไว้ในตัวแปรสภาพแวดล้อมบนเซิร์ฟเวอร์แล้วรันคำขอ อย่าใส่คีย์ไว้ในโค้ดฝั่งเบราว์เซอร์หรือรีโพสิทอรีสาธารณะ
5. ตรวจสอบการตอบกลับ สำหรับงานแบบอะซิงโครนัส ให้ทำตามตัวอย่างการโพลสถานะของเอนด์พอยต์จนกว่างานจะเสร็จ

ตัวอย่างการเรียกโมเดลภาษาสำหรับ **Bash / zsh** (macOS, Linux หรือ Windows ที่ใช้ WSL) ให้แทนที่คีย์ตัวอย่างในเครื่องของคุณ สำหรับสภาพแวดล้อมอื่น ให้ใช้ตัวอย่าง Python, TypeScript หรือ Go ในรีโพสิทอรีด้านล่าง คำสั่งเชลล์ใช้แทนกันกับ PowerShell ไม่ได้

```bash
export SANDBASE_API_KEY="sk-YOUR_KEY"

curl https://api.sandbase.ai/v1/chat/completions \
  -H "Authorization: Bearer $SANDBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek/deepseek-v4-flash",
    "messages": [{"role": "user", "content": "Reply with one sentence explaining what an API is."}]
  }'
```

เริ่มจากโค้ด: [SDK และตัวอย่างของ SandBase บน GitHub](https://github.com/sandbaseai/sandbase)

เรียนรู้เพิ่มเติม: [การเรียก API ครั้งแรก](/getting-started/first-call)

## ใช้กับ Agent ของคุณ {#use-in-ai-tool}

เลือกวิธีนี้หากคุณใช้ Claude Code, Codex, Cursor, Kiro หรือไคลเอนต์อื่นที่รองรับ และต้องการใช้ Models และ APIs ของ SandBase ภายในแอปนั้น

**สำหรับการตั้งค่าในเครื่องแบบอัตโนมัติ:** ไคลเอนต์ของคุณต้องรันคำสั่งได้ และเครื่องต้องมี Node.js 20+ พร้อม npm หากคุณใช้ไคลเอนต์ที่แชตได้อย่างเดียว ให้ทำตาม[คำแนะนำการเชื่อมต่อเฉพาะไคลเอนต์](/setup/)แทน

1. เปิด [Build → AI tools](https://www.sandbase.ai/console/setup){target="_blank"} ใน Console
2. วางบรรทัดนี้ลงในแชตของผู้ช่วย AI แล้วบอกสิ่งที่คุณต้องการสร้าง นี่คือคำสั่งในแชต ไม่ใช่คำสั่งเชลล์:

   ```text
   set up https://www.sandbase.ai/SKILL.md
   ```

3. อนุมัติการลงชื่อเข้าใช้ในเบราว์เซอร์ที่ agent เปิดขึ้น ไม่ต้องวาง API key
4. เริ่ม session ใหม่หรือรีสตาร์ตแอปเพื่อให้เครื่องมือ SandBase โหลดขึ้นมา
5. ขอให้ agent ค้นหาและตรวจสอบเครื่องมือที่เกี่ยวข้อง แล้วส่งคำขอที่มีขอบเขตชัดเจนหนึ่งครั้งภายในสิทธิ์และงบประมาณของคุณ สำหรับงานพัฒนา ให้ agent ผสานการตอบกลับเข้ากับโปรเจกต์ของคุณ และแจ้งคำสั่งรันพร้อมผลการทดสอบจริง การค้นหาเพียงอย่างเดียวไม่ได้ยืนยันว่าการเรียก API ทางธุรกิจทำงานได้

ชอบใช้เทอร์มินัลมากกว่าใช่ไหม รัน `npx -y @sandbaseai/cli@latest connect` คำสั่งนี้จะกำหนดค่าไคลเอนต์ที่รองรับซึ่งตรวจพบ หากต้องการกำหนดค่าเพียงตัวเดียว ให้ใช้ `npx -y @sandbaseai/cli@latest connect --client codex` (แทนที่ `codex` ด้วยไคลเอนต์ที่รองรับของคุณ) จากนั้นรีสตาร์ตไคลเอนต์นั้น ตรวจสอบ workspace ที่เลือกก่อนรันงานที่มีค่าใช้จ่าย

ตัวอย่างเช่น คุณอาจถามว่า:

> ค้นหา SandBase API สำหรับค้นหาโพสต์สาธารณะบน X เกี่ยวกับ AI agent ตรวจสอบ input ที่จำเป็นและราคาก่อน แล้วบอกค่าใช้จ่ายของคำขอหนึ่งครั้งก่อนรัน เก็บลิงก์แหล่งที่มาดั้งเดิมไว้ในผลลัพธ์

ซอร์สโค้ดและคำแนะนำการติดตั้ง: [SandBase CLI และ MCP บน GitHub](https://github.com/sandbaseai/cli)

เรียนรู้เพิ่มเติม: [เชื่อมต่อ AI tools](/setup/)

### ให้ผู้ช่วย AI ช่วยคุณสร้าง {#start-with-your-agent}

[Skill สำหรับการตั้งค่า](https://www.sandbase.ai/SKILL.md) จะแนะนำ agent ของคุณตามสถานการณ์ปัจจุบัน: ยังไม่มีบัญชี มี API key อยู่แล้ว มีเครื่องมือที่เชื่อมต่อแล้ว มีโปรเจกต์อยู่แล้ว หรือกำลังสร้างฟีเจอร์ใหม่ Skill นี้จะตรวจสอบ input และราคาของเอนด์พอยต์ ช่วยลงมือผสานระบบ และแยกให้เห็นว่าการตั้งค่าต่างจากการเรียกที่ยืนยันแล้วและฟีเจอร์ที่ใช้งานได้จริงอย่างไร บอกเป้าหมายและขีดจำกัดการใช้จ่ายของคุณ และอย่าวางคีย์ลงในแชต

มีคีย์หรือโปรเจกต์อยู่แล้วใช่ไหม บอกไปได้เลย ไม่ต้องเริ่มใหม่ ตัวอย่างเช่น: “ฉันมีคีย์ SandBase แล้ว เพิ่มการค้นหาข้อมูลทราฟฟิกของ Similarweb ลงในโปรเจกต์นี้ ตรวจสอบ API และแสดงค่าใช้จ่ายของการทดสอบจริงก่อน” ผู้ช่วยที่รันคำสั่งหรือโหลดเครื่องมือไม่ได้ต้องใช้[เส้นทางการตั้งค่าเฉพาะไคลเอนต์](/setup/)

[ส่ง Quickstart แบบ Markdown ให้ agent ของคุณ](https://www.sandbase.ai/quickstart.md) หรือทำตามขั้นตอนด้านล่าง การติดตั้ง Skill สำหรับการตั้งค่าไม่ได้สร้าง Agent ที่โฮสต์ไว้ให้โดยอัตโนมัติ

### ไม่บังคับ: รัน Agent ที่โฮสต์บน SandBase {#build-agent}

เลือกวิธีนี้หากงานมีหลายขั้นตอนหรือควรนำกลับมาใช้ซ้ำ

1. เปิด [Build → Agents](https://www.sandbase.ai/console/agents){target="_blank"} แล้วเลือก **Create**
2. กรอก **Overview** และ **Instructions**
3. เลือก **Model**
4. เพิ่ม Skills และเครื่องมือ MCP ภายใต้ **Capabilities** แล้วตั้งค่า **Runtime**
5. เลือก **Create & Chat** เพื่อทดสอบใน Session
6. เรียกเวอร์ชันที่ทดสอบแล้วจากแอปของคุณผ่านแท็บ **API** ของ Agent

เรียนรู้เพิ่มเติม: [Build Agent](/agents/) หากต้องการทำแบบเดียวกันจากโค้ดด้วย OpenAI SDK ทางการ โปรดดู[ความเข้ากันได้กับ OpenAI](/agents/openai-compatibility)

## Skills, Tools และวิธีอื่นในการสร้าง {#skills-and-tools}

เลือกทรัพยากรที่ตรงกับงานของคุณ คุณไม่จำเป็นต้องติดตั้ง Skill หรือสร้าง Agent ที่โฮสต์ไว้เพื่อใช้ API

- **[Tools](https://www.sandbase.ai/tools):** ทำงานเฉพาะอย่างให้เสร็จในอินเทอร์เฟซสำเร็จรูป เช่น จัดรูปแบบข้อความหรือค้นหาข้อมูลสาธารณะ
- **[Skills](https://www.sandbase.ai/skills):** มอบเวิร์กโฟลว์ที่นำกลับมาใช้ซ้ำได้ให้ agent พร้อมคำสั่ง สคริปต์ และตัวอย่าง
- **Models และ APIs:** เรียกใช้ความสามารถจาก Playground โค้ดของคุณ หรือ agent ที่เชื่อมต่อไว้ สำรวจ[โมเดลภาษา](https://www.sandbase.ai/models) [ภาพและวิดีโอ](https://www.sandbase.ai/models/image-video) หรือ [data APIs](https://www.sandbase.ai/apis)
- **[Agents ที่โฮสต์ไว้](/agents/):** กำหนดค่าและรัน agent ที่นำกลับมาใช้ซ้ำได้บน SandBase
- **[Sandboxes](/sandbox/):** มอบสภาพแวดล้อมแบบแยกส่วนให้โค้ดได้รันและทำงานกับไฟล์

### ใช้ Tool {#use-tools}

1. เปิด [Tools](https://www.sandbase.ai/tools) แล้วเลือกงานที่คุณต้องการทำ
2. อ่านข้อกำหนด input และป้ายราคาหรือโควตาของเครื่องมือ เครื่องมืออรรถประโยชน์ฟรีอาจใช้ได้โดยไม่ต้องมีบัญชี เครื่องมือข้อมูลต้องลงชื่อเข้าใช้ SandBase ก่อนรัน และการทดสอบโมเดลอาจต้องใช้คีย์ของคุณเอง
3. ป้อนข้อความ URL ไฟล์ หรือ input อื่นที่ขอ แล้วใช้คำสั่งรันของเครื่องมือ
4. ตรวจสอบเอาต์พุตและใช้คำสั่งคัดลอกหรือดาวน์โหลดหากมี สำหรับเครื่องมือข้อมูล ให้ใช้ API และตัวอย่างคำขอที่ลิงก์ไว้หากต้องการทำงานเดียวกันแบบอัตโนมัติ

**โควตาฟรีรายวันใช้ร่วมกันทั้ง workspace** ไม่ใช่โควตาแยกสำหรับแต่ละเครื่องมือ ตรวจสอบสิทธิ์และราคาที่แสดงก่อนรัน เครื่องมืออรรถประโยชน์ที่ฟรีไม่ได้ทำให้การเรียกโมเดลหรือ API ฟรีไปด้วย

### ใช้ Skill {#use-skills}

1. เปิด [Skills](https://www.sandbase.ai/skills) เลือกเวิร์กโฟลว์ แล้วอ่านตัวอย่าง input ที่จำเป็น และสิ่งที่ต้องพึ่งพา
2. เลือกตัวเลือกหนึ่งที่มีในหน้ารายละเอียดของ Skill นั้น:
   - **Run online:** ลงชื่อเข้าใช้แล้วรันตัวอย่างที่โฮสต์ไว้หากมี ติดตามความคืบหน้าแล้วเปิดเอาต์พุตหรือไฟล์ที่ได้ ตรวจสอบโควตาที่แสดง ความพร้อมใช้งานและขีดจำกัดแตกต่างกันไปตาม Skill
   - **Install / Download:** ลงชื่อเข้าใช้เพื่อดาวน์โหลดแพ็กเกจหากมี แตกแพ็กเกจทั้งหมดลงในโฟลเดอร์ทำงาน แล้วทำตามคำแนะนำการติดตั้ง หรือขอให้ agent ในเครื่องอ่าน `SKILL.md`
3. สำหรับการใช้งานในเครื่อง ให้ระบุงาน input เอาต์พุตที่ต้องการ และขีดจำกัดการใช้จ่าย เชื่อมต่อ SandBase โดยใช้[เส้นทางสำหรับ Agent](#use-in-ai-tool) หากสคริปต์ของ Skill ต้องใช้คีย์ ให้กำหนดค่าในสภาพแวดล้อมที่รันแทนการวางลงในแชต
4. ตรวจสอบผลลัพธ์จริง การดาวน์โหลด Skill หรือการเชื่อมต่อ agent ไม่ได้หมายความว่าเวิร์กโฟลว์รันสำเร็จแล้ว

**Skill สำหรับการตั้งค่า**ของ SandBase ใช้เชื่อมต่อไคลเอนต์ของคุณ ส่วน Skills ในแคตตาล็อกอธิบายเวิร์กโฟลว์แต่ละแบบ ตรวจสอบสิ่งที่ต้องพึ่งพาและไคลเอนต์ที่รองรับของแต่ละ Skill ก่อนติดตั้ง การเรียกโมเดลและ API ที่เวิร์กโฟลว์ในเครื่องใช้อาจมีค่าใช้จ่ายตามการใช้งาน

ดูขั้นตอนทั้งหมด รวมถึงโฟลเดอร์ input และผลงานที่บันทึกไว้ได้ที่[ใช้ Skill ในเครื่อง](/guides/skills/local-use)

## ไม่บังคับ: แชร์ workspace ของทีม {#create-organization}

API key การใช้งาน และการเรียกเก็บเงินเป็นขององค์กร หากคุณประเมินใช้งานคนเดียว ให้ใช้ workspace ส่วนตัวต่อไป สร้างทีมเมื่อหลายคนจะใช้คีย์และค่าใช้จ่ายร่วมกัน

| Workspace | เมื่อใดควรใช้ |
|---|---|
| **ส่วนตัว** | สร้างอัตโนมัติเมื่อเข้าสู่ระบบครั้งแรก ผู้ใช้แต่ละคนมีได้หนึ่งรายการ |
| **ทีม** | ใช้สมาชิก คีย์ และยอดเงินร่วมกัน สร้างสำหรับบริษัทหรือโปรเจกต์ |

### สร้างทีม {#create-team}

1. เปิด[สร้างทีม](https://www.sandbase.ai/console/members?create=1){target="_blank"} หรือเลือก **Create Team** ในเมนูบัญชีที่มุมขวาบนของ Console
2. ป้อน **Team name** แล้วเลือก **Create team**
3. ยืนยันว่าเมนูบัญชีแสดงทีมนั้นเป็น workspace ที่ใช้งานอยู่
4. ใน **Developer → Team** เลือก **Add member** ป้อน **Account email** ของบัญชี SandBase ที่มีอยู่ แล้วเลือก **Workspace role** (Member หรือ Admin)

ผู้ที่ได้รับเชิญต้องมีบัญชี SandBase อยู่แล้ว หากยังไม่มี ให้ส่ง[หน้านี้](/getting-started/quickstart)ให้เขาลงชื่อเข้าใช้ก่อน แล้วจึงเพิ่มเข้าทีม

หากคุณอยู่ในหลายองค์กร ให้สลับได้ในเมนูบัญชี คีย์และการเรียกเก็บเงินจะเป็นไปตามองค์กรที่**ใช้งานอยู่** ดูบทบาทต่าง ๆ ได้ที่[องค์กร](/admin/organizations)

## ยืนยันว่าใช้งานได้ {#confirm-it-works}

คุณพร้อมแล้วเมื่อทุกข้อต่อไปนี้เป็นจริง:

- เมนูบัญชีใน Console แสดงองค์กรที่คุณต้องการใช้
- คุณทำเส้นทางใดเส้นทางหนึ่งเสร็จแล้ว: การเรียก API การรันบนเว็บไซต์ เครื่องมือ AI ที่เชื่อมต่อแล้ว หรือ Agent
- คำขอหนึ่งรายการสำเร็จ

หากคำขอล้มเหลว ให้ตรวจสอบองค์กรที่ใช้งานอยู่ คีย์ และ[ข้อผิดพลาด](/guides/error-handling) เติมเงินใน [Billing](https://www.sandbase.ai/console/billing){target="_blank"} เมื่อ workspace ไม่มียอดเงินเหลือ

### หากติดปัญหา {#if-you-get-stuck}

| สิ่งที่คุณเห็น | สิ่งที่ควรตรวจสอบ |
| --- | --- |
| ต้องลงชื่อเข้าใช้ | ลงชื่อเข้าใช้ กลับไปยังหน้าเดิม และตรวจสอบ workspace ที่ใช้งานอยู่ |
| คีย์ไม่ถูกต้องหรือถูกปฏิเสธการเข้าถึง | ยืนยันว่าคีย์เป็นของ workspace ที่ต้องการและมีสิทธิ์เข้าถึงเอนด์พอยต์ การเพิ่มเครดิตไม่ได้แก้ปัญหาสิทธิ์ |
| ยอดเงินไม่พอหรือโควตาหมด | อ่านการตอบกลับ: ตรวจสอบ Billing หากเป็นปัญหายอดเงิน หรือดูเวลารีเซ็ตที่แสดงหากเป็นขีดจำกัดโควตา |
| ไม่มีเครื่องมือใน Agent ของคุณ | เริ่ม session ใหม่ของไคลเอนต์ แล้วทำตามการวินิจฉัยใน[เชื่อมต่อ AI tools](/setup/) |
| งานยังทำงานอยู่ | ติดตามสถานะงานที่ส่งคืนหรือตัวแสดงความคืบหน้าของหน้า หลีกเลี่ยงการส่งคำขอที่มีค่าใช้จ่ายเดิมซ้ำ ๆ |
