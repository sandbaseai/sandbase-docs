# เริ่มต้นใช้งาน SandBase {#getting-started-with-sandbase}

SandBase ช่วยให้ Agent ของคุณเชื่อมต่อกับโลกจริง

หากคุณเพิ่งเริ่มใช้งาน ให้เริ่มที่ [Quickstart](/getting-started/quickstart): สร้างบัญชี ตั้งค่าองค์กร แล้วส่งคำขอจริงหนึ่งครั้ง

หลังจากนั้น คุณใช้ SandBase ได้สี่วิธี:

| แนวทาง | เหมาะสำหรับ | สิ่งที่คุณจะได้ |
|---|---|---|
| **เรียก Models และ APIs** | นักพัฒนาและผู้สร้าง | คำขอที่ใช้งานได้ซึ่งเรียกจากแอปพลิเคชันของคุณได้ |
| **ใช้บนเว็บไซต์** | การทดลองความสามารถในเบราว์เซอร์ | หน้ารายละเอียดในแคตตาล็อกที่เรียกใช้ได้โดยไม่ต้องเขียนโค้ด |
| **Setup** | ผู้ที่ใช้ Codex, Claude, Cursor หรือ Kiro | Models และ APIs ที่มีประโยชน์ภายในแอป AI ของคุณ |
| **Build Agent** | FDE และทีมที่สร้างเวิร์กโฟลว์ที่นำกลับมาใช้ซ้ำได้ | Agent ที่คุณทดสอบและเรียกใช้ใน Session ได้ |

## แนวคิดหลัก {#core-ideas}

### แคตตาล็อก {#catalog}
แคตตาล็อกบนเว็บไซต์ SandBase คือที่ที่คุณค้นหาความสามารถต่างๆ:

- **Models** สำหรับการให้เหตุผล ข้อความ ภาพ เสียง และวิดีโอ
- **APIs** สำหรับการค้นหา การดึงข้อมูลเว็บ ข้อมูล สื่อ SaaS และตัวเชื่อมต่อ
- **Agents** เป็นตัวอย่างสำเร็จรูปที่คุณทดสอบหรือ clone ได้
- **Skills** เป็นแพ็กเกจงานที่นำกลับมาใช้ซ้ำได้สำหรับ Agent

### Setup {#setup}

Setup นำความสามารถต่างๆ เข้าไปไว้ในเครื่องมือ AI ที่คุณใช้อยู่แล้ว

ใช้เมื่อคุณต้องการให้มีเครื่องมือพร้อมใช้ภายใน Codex, Claude, Cursor หรือ Kiro โดยไม่ต้องสร้าง Agent ใหม่ตั้งแต่ต้น

### Build Agent {#build-agent}

Build Agent คือที่ที่คุณกำหนดและทดสอบ Agent ของคุณเอง

Agent รวม Model, คำสั่ง, Skills และเครื่องมือ MCP ไว้เป็นหน่วยเดียวที่นำกลับมาใช้ซ้ำได้และมีเวอร์ชัน

เมื่อ Agent ทำงานได้แล้ว คุณสามารถ:

- เรียกใช้ใน Session จากแอปพลิเคชันของคุณ
- ตรวจสอบแต่ละ Session ใน Console

## ควรเริ่มจากตรงไหน {#where-should-i-start}

หากยังไม่มีบัญชี ให้เริ่มที่ [Quickstart](/getting-started/quickstart)

หากต้องการเรียกความสามารถหนึ่งจากโค้ด ให้ดู [แคตตาล็อกโมเดล](https://www.sandbase.ai/models) หรือ [แคตตาล็อก API](https://www.sandbase.ai/apis) แล้วใช้เอกสารและตัวอย่างคำขอที่ตรงกัน

หากต้องการลองความสามารถในเบราว์เซอร์ก่อน ให้เปิดหน้ารายละเอียดในแคตตาล็อกบน [sandbase.ai](https://www.sandbase.ai/models)

หากต้องการเครื่องมือในแอป AI ของคุณ ให้เริ่มที่ [Setup](/setup/)

หากต้องการเวิร์กโฟลว์ที่ทำซ้ำได้ ให้เริ่มที่ [Build Agent](/agents/)
