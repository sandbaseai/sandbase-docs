# Models API {#models-api}

ใช้ Models API เพื่อค้นหาโมเดลก่อนเลือก endpoint สำหรับ inference การดำเนินการแสดงรายการเข้ากันได้กับ OpenAI และส่งคืนระเบียนข้อมูลระบุตัวตนแบบกระชับ ให้ดึงข้อมูลโมเดลทีละรายการเพื่อดู metadata ด้านความสามารถ schema และราคาของ SandBase

| การดำเนินการ | Endpoint | เอกสาร |
|---|---|---|
| แสดงรายการโมเดล | `GET /v1/models` | [แสดงรายการโมเดล](./list) |
| ดูโมเดลหนึ่งรายการ | `GET /v1/models/{id_or_name}` | [ดูโมเดล](./get) |
| เรียกใช้ความสามารถของ API ตามพาธ | `GET/POST /v1/api/{vendor}/{upstream_path}` | [API Passthrough](./api-passthrough) |
| รันโมเดลหรือความสามารถของ API | `POST /v1/run` | [รันความสามารถ](./run) |
| ดูผลลัพธ์แบบ asynchronous | `GET /v1/run/{id}` | [ดูผลการรัน](./run-get) |
| รับ callback แบบ asynchronous | `webhook_url` ใน `POST /v1/run` | [Webhook callback](./run#webhook-callbacks) |
| เรียกดูโมเดลที่รองรับ | — | [แค็ตตาล็อกโมเดล](https://www.sandbase.ai/models) |

หากต้องการรันโมเดล ให้เปิดหน้าอ้างอิงของโมเดลนั้นจาก[แค็ตตาล็อกโมเดล](https://www.sandbase.ai/models) แต่ละหน้าจะแสดงตัวระบุที่ถูกต้อง ฟิลด์ของคำขอ และราคา หน้านี้อธิบายการค้นหาโมเดล ตัวรันความสามารถแบบรวม API passthrough, asset และการค้นหาค่าใช้จ่ายของงาน

`GET /v1/models` รองรับ `q`, `vendor`, `type` และ `order` และไม่มีการแบ่งหน้า หากไม่ระบุ `type` ค่าเริ่มต้นคือ `llm` ส่วน `type=` ที่ระบุเป็นค่าว่างอย่างชัดเจนจะแสดงโมเดลสาธารณะทุกประเภท ตัวกรอง `vendor` ต้องตรงตัวและแยกตัวพิมพ์เล็ก-ใหญ่ ส่วน `q` เป็นการค้นหาสตริงย่อยที่ไม่แยกตัวพิมพ์เล็ก-ใหญ่ แต่ละรายการมี `id`, `object`, `created` และ `owned_by` โดย `id` คือชื่อโมเดลเชิงตรรกะที่ใช้ในคำขอ

ชื่อโมเดลอาจมี `/` ให้ส่งเครื่องหมายทับเหล่านั้นเป็นตัวคั่นพาธเมื่อเรียก endpoint รายละเอียด เช่น `/v1/models/openai/gpt-5.6-luna` โดยเส้นทางของเซิร์ฟเวอร์จะถือว่าพาธที่เหลือทั้งหมดเป็นตัวระบุเชิงตรรกะเดียว ให้ค้นหา ID ปัจจุบันจาก `GET /v1/models` แทนการคัดลอกตัวระบุจากคู่มือเก่า

สำหรับ response `202` แบบ asynchronous จาก inference API ให้ poll `GET /v1/run/{id}` ด้วย ID แบบทึบที่ได้รับ อย่าอนุมาน prefix ของ ID หรือสร้างพาธ polling อื่นจากเฮดเดอร์ด้านความเข้ากันได้
