# Account API {#account-api}

เอนด์พอยต์ของบัญชีเป็นแบบอ่านอย่างเดียว และทำงานกับองค์กรที่ระบุได้จาก Bearer API key

| การดำเนินการ | เอนด์พอยต์ |
|---|---|
| [ดูยอดเงินคงเหลือ](./balance) | `GET /v1/account/balance` |
| [แสดงรายการประวัติการทำงาน](./history) | `GET /v1/account/history` |

ค่ายอดเงินและค่าใช้จ่ายเป็นสตริงทศนิยมที่แม่นยำ ให้เก็บเป็นค่าทศนิยม แทนการแปลงผ่าน
การคำนวณเลขทศนิยมลอยตัวแบบไบนารี

ประวัติการทำงานมีไว้สำหรับตรวจสอบการทำงานในช่วงล่าสุด ให้ใช้บันทึกการเรียกเก็บเงินหรือไฟล์ส่งออกสำหรับ
การกระทบยอดทางการเงินในระยะยาว

การกรองประวัติใช้ timestamp แบบ UTC ดิบ เมื่อไม่มี `request_id` พารามิเตอร์ความเข้ากันได้ `timezone` (ไม่บังคับ) จะถูกตรวจสอบว่าเป็นชื่อเขตเวลาของ IANA แต่จะไม่แปลง timestamp ในการตอบกลับ ส่วนโหมด `request_id` แบบตรงตัวจะละเว้นพารามิเตอร์นี้พร้อมกับตัวกรองอื่น ๆ ค่า `type` ที่ไม่รู้จักจะไม่ใช้ตัวกรองประเภทการทำงาน ให้ใช้ `multimodal`, `llm` หรือ `api` เพื่อให้ตัวกรองมีผล ค่า `range` ที่ไม่รองรับจะใช้ `7d` แทน

รายการประวัติอาจมีพารามิเตอร์คำขอที่จัดเก็บไว้และเอาต์พุตของโมเดล ให้จำกัดการเข้าถึง API key ให้เหมาะสม
และอย่าคัดลอกการตอบกลับของประวัติลงในล็อกหรือตั๋วขอความช่วยเหลือโดยไม่ตรวจสอบข้อมูลที่ละเอียดอ่อนก่อน
