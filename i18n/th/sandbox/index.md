# ภาพรวมและความสามารถของ Sandbox {#sandbox-overview-and-capabilities}

Sandbox มีสภาพแวดล้อมแบบแยกส่วนสำหรับรันคำสั่ง รันโค้ด และอ่านหรือเขียนไฟล์ คุณสามารถหยุดอินสแตนซ์ชั่วคราว เชื่อมต่อกลับ และอ่านไฟล์อีกครั้งเพื่อตรวจสอบว่าข้อมูลยังคงอยู่

[เริ่มต้นอย่างรวดเร็ว / E2B SDK](./quickstart) · [เปิด Playground (ทดลอง)](./playground)

ใช้ [E2B SDK อย่างเป็นทางการ](./quickstart) เพื่อผสาน Sandbox เข้ากับแอปพลิเคชันของคุณ ลงชื่อเข้าใช้ [Sandbox Console](https://www.sandbase.ai/console/sandboxes) เพื่อสร้าง sandbox และดูสถานะ บันทึก และเมตริกของอินสแตนซ์ ดูข้อมูลเบื้องต้นได้ที่ [ภาพรวมผลิตภัณฑ์ Sandbox](https://www.sandbase.ai/sandbox) ขั้นตอนแนะนำและตารางการรองรับด้านล่างอธิบายถึง Playground แบบทดลองซึ่งแยกต่างหาก

## ทดลองใช้ Playground ในห้านาที {#a-five-minute-playground-walkthrough}

1. กรอก [API key](/getting-started/api-keys) ที่มีสิทธิ์ Sandbox การเชื่อมต่อจะอ่านเฉพาะเทมเพลตและอินสแตนซ์เท่านั้น
2. เลือกเทมเพลตที่มี รับทราบประกาศเกี่ยวกับทรัพยากร แล้วสร้างอินสแตนซ์อายุสั้น
3. รันตัวอย่างข้อมูลระบบหรือตัวอย่าง Python ดูเอาต์พุตและอีเวนต์ของโปรเซสข้างแผงคำสั่ง
4. เขียนและตรวจสอบไฟล์ข้อความ หยุดอินสแตนซ์ชั่วคราว กลับมาทำงานต่อ แล้วอ่านไฟล์เดิมอีกครั้ง
5. ตรวจสอบอีเวนต์วงจรชีวิต เมตริก บันทึก และหลักฐานเวลาเครื่อง ลบอินสแตนซ์เมื่อใช้งานเสร็จ

การรีเฟรชจะล้างข้อมูลรับรองในหน้าและประวัติการดำเนินการบนเครื่อง แต่จะไม่ลบ sandbox อินสแตนซ์ที่กำลังรันจะทำงานตามระยะหมดเวลาของเซิร์ฟเวอร์ อินสแตนซ์ที่หยุดชั่วคราวอาจยังคงใช้ทรัพยากร ให้บันทึก ID ของอินสแตนซ์ และใช้เครื่องมือขององค์กรเพื่อกระทบยอดและล้างทรัพยากรหลังออกจากหน้า

## ความสามารถและขอบเขต {#capabilities-and-boundaries}

| ความสามารถ | การรองรับใน Playground |
| --- | --- |
| สร้าง แสดงรายการ หยุดชั่วคราว กลับมาทำงานต่อ ขยายระยะหมดเวลา ลบ | ใช้ได้ การควบคุมที่เปลี่ยนแปลงข้อมูลใช้ได้เฉพาะกับอินสแตนซ์ที่สร้างใน session ของหน้านี้ |
| คำสั่งและไฟล์ข้อความ | ใช้ได้ คำสั่งรันได้สูงสุด 25 วินาที และการแก้ไขไฟล์จำกัดเฉพาะ `/tmp/` และไม่เกิน 32 KiB |
| อีเวนต์วงจรชีวิต บันทึก เมตริก เวลาเครื่อง | ความพร้อมใช้งานขึ้นอยู่กับสภาพแวดล้อม ให้ตรวจสอบผลลัพธ์ที่ส่งคืน |
| แชต AI และบริบทของบทสนทนา | ไม่ได้ผสานไว้ ต้องมีการกำหนดค่าโมเดลและเวิร์กโหลด Agent |
| PTY, พอร์ตของแอปพลิเคชัน, webhook, การสร้างเทมเพลต | ไม่มีในอินเทอร์เฟซนี้ |
| Snapshot และ fork | ไม่มีใน Playground นี้ |

การโต้ตอบกับ shell ไม่ใช่แชต AI การกู้คืนอินสแตนซ์ การคงอยู่ของไฟล์ การอยู่รอดของโปรเซส และความต่อเนื่องของบทสนทนาเป็นสิ่งที่ต้องตรวจสอบแยกกัน

## ทำความเข้าใจอีเวนต์ {#understanding-events}

รายการ **Sandbox lifecycle** เป็นอีเวนต์เนทีฟของเซิร์ฟเวอร์ที่ดึงมาเมื่อรีเฟรช และอาจมาถึงล่าช้า รายการ **Sandbox process** อธิบายการเริ่มโปรเซสและเอาต์พุตที่สตรีม รายการ **Playground** บันทึกว่าคำขอบนเครื่องเสร็จสมบูรณ์หรือล้มเหลว และไม่ใช่อีเวนต์วงจรชีวิตของบริการ

รายการที่ว่างเปล่าไม่ได้พิสูจน์ว่าไม่มีการใช้งาน และอีเวนต์ที่ขาดหายไปก็ไม่ได้พิสูจน์ว่าการดำเนินการล้มเหลว หลักฐานเวลาเครื่องไม่ใช่ใบเรียกเก็บเงินสุดท้าย ให้กระทบยอดอินสแตนซ์หลังหมดเวลาหรือการเชื่อมต่อถูกขัดจังหวะก่อนลองส่งคำขอสร้างอีกครั้ง

## การมองเห็นเทมเพลต {#template-visibility}

เทมเพลตอาจเป็นแบบสาธารณะหรือแบบส่วนตัวสำหรับองค์กรของคุณ จำนวนเทมเพลตไม่คงที่ รายการที่ไม่มีชื่อจะยังมองเห็นได้ โดยใช้ alias หรือ ID เป็นป้ายชื่อแทน สิทธิ์การเข้าถึงขององค์กรและความพร้อมใช้งานของเทมเพลตเป็นตัวกำหนดว่าคุณจะเห็นและใช้เทมเพลตใดได้บ้าง

## Sandbox และ Agent Session {#sandboxes-and-agent-sessions}

Agents Session รันบนคลาวด์ที่ SandBase โฮสต์ไว้ ซึ่งแยกจากอินสแตนซ์ Sandbox ที่คุณสร้างด้วย E2B SDK และ Agents API ไม่ได้เปิดให้เข้าถึงอินสแตนซ์ Sandbox ดู [Sessions](/agents/sessions)
