# Sandbox Playground {#sandbox-playground}

ลองใช้ Sandbox API ด้วยคีย์ของคุณเอง การดำเนินการจะเชื่อมต่อกับ **sandbox.sandbase.ai** และอาจมีค่าใช้จ่าย

</ClientOnly>

## คีย์ของคุณอยู่ในการควบคุมของคุณ {#your-key-stays-under-your-control}

- **เก็บในหน่วยความจำของหน้าเท่านั้น** Playground นี้ไม่บันทึก API key หรือโทเค็นการเชื่อมต่อของคุณลงในพื้นที่จัดเก็บของเบราว์เซอร์หรือคุกกี้ ไม่ใส่ไว้ใน URL และไม่บันทึกไว้ในกิจกรรมของหน้าหรือตัวอย่างคำขอ
- **ล้างได้ทุกเมื่อ** เลือก **Clear key** เพื่อลบคีย์ โทเค็นการเชื่อมต่อ และกิจกรรมที่แสดง แม้ในขณะที่คำขอกำลังทำงาน การรีเฟรชหรือออกจากหน้านี้ก็จะล้างข้อมูลเหล่านี้ด้วย คุณจะต้องป้อนคีย์อีกครั้งเพื่อเชื่อมต่อใหม่
- **ใช้สำหรับคำขอของคุณเท่านั้น** คีย์ของคุณจะถูกส่งไปยัง SandBase เพื่อยืนยันตัวตนสำหรับการดำเนินการ Sandbox ที่คุณร้องขอ การล้างหน้านี้ไม่ได้เพิกถอนคีย์ หากจำเป็น ให้เพิกถอนใน [Developer → API Keys](https://www.sandbase.ai/console/keys)

คำมั่นเหล่านี้ครอบคลุมการจัดการข้อมูลรับรองของ Playground นี้ ไม่ได้หมายความว่ากิจกรรมของ Sandbox หรือบันทึกการใช้งานฝั่งบริการจะถูกลบ หลีกเลี่ยงการป้อนข้อมูลลับในคำสั่งหรือไฟล์ เพราะเนื้อหาอาจยังคงอยู่ใน sandbox ของคุณ

## ล้างทรัพยากรแยกต่างหาก {#clean-up-resources-separately}

การล้างคีย์ไม่ได้ยกเลิกการดำเนินการที่บริการได้รับไปแล้ว และไม่ได้ลบ sandbox ให้ลบอินสแตนซ์เมื่อใช้งานเสร็จ หากไม่ทราบผลของการสร้าง ให้ตรวจสอบอินสแตนซ์ของคุณก่อนสร้างใหม่ เก็บ ID ของอินสแตนซ์ที่ต้องใช้ในการล้างไว้ก่อนล้างหน้านี้
