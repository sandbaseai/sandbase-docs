# เข้าร่วม AI City Remix {#enter-ai-city-remix}

เลือก Skill และเมืองในหน้ากิจกรรม แล้วส่งคำสั่งฉบับสมบูรณ์ให้ agent ในเครื่องของคุณ หลังจากสร้างผลงานเสร็จ agent จะอัปโหลดวิดีโอ ภาพปก และรายละเอียดผลงาน แล้วส่งเข้ารับการตรวจสอบ


## สิ่งที่ต้องมี {#prerequisites}

- บัญชี SandBase
- agent ในเครื่องที่เรียกใช้คำสั่งและเข้าถึงไฟล์ได้
- โฟลเดอร์ทำงานสำหรับวิดีโอ ภาพปก และไฟล์โปรเจกต์

สำหรับการตั้งค่าในเครื่องครั้งแรก ให้ทำตาม [ใช้ Skill ในเครื่อง](/guides/skills/local-use)

## 1. เปิดหน้ากิจกรรมและรับเครดิต {#_1-open-the-event-and-claim-credits}

1. เปิด [AI City Remix](https://www.sandbase.ai/lab/event/aicityremix?lang=en) และอ่าน[กติกากิจกรรม](https://www.sandbase.ai/lab/event/aicityremix?tab=rules&lang=en)ฉบับปัจจุบัน
2. คลิก “รับฟรี $5 และเริ่มสร้าง” แล้วเข้าสู่ระบบเมื่อระบบแจ้ง
3. ระบบจะรับเครดิตกิจกรรมและพยายามแลกให้อัตโนมัติ ตรวจสอบยอดคงเหลือและสถานะการแลก หากต้องลองใหม่ ให้ใช้ปุ่มแลกเครดิต
4. หลังจากรับเครดิตแล้ว คลิก “สร้างเลย” เพื่อเปิดหน้าต่างการสร้าง

วันที่รับเครดิต ความพร้อมใช้งาน และคุณสมบัติผู้มีสิทธิ์จะแสดงในหน้ากิจกรรม การเรียกใช้โมเดลจะใช้เครดิตตามการใช้งานจริง ตรวจสอบได้ที่ [Billing](https://www.sandbase.ai/console/billing)

## 2. กำหนดค่า API key ของโมเดล {#_2-configure-a-model-api-key}

หากบัญชีของคุณไม่มี API key ที่ใช้งานได้ ขั้นตอนนี้จะแสดงหน้าต่าง “สร้าง API key”

1. ตรวจสอบวงเงินการใช้จ่ายและวันหมดอายุที่แสดง แล้วคลิก “สร้าง API key”
2. คลิก “สร้างด้วยคีย์นี้” คีย์ใหม่จะรวมอยู่ในคำสั่งฉบับสมบูรณ์ที่ส่งให้ agent
3. ส่งคำสั่งฉบับสมบูรณ์ให้ agent ที่คุณไว้วางใจ และเก็บไว้ในเวิร์กสเปซส่วนตัว

สำหรับคีย์ที่มีอยู่แล้ว ให้กำหนดค่า `SANDBASE_API_KEY` ผ่านการตั้งค่าที่ปลอดภัยหรือสภาพแวดล้อมการทำงานของ agent ในเครื่อง จัดการคีย์ได้ที่ [API Keys](https://www.sandbase.ai/console/keys)

## 3. เลือก Skill และโจทย์ {#_3-choose-a-skill-and-brief}

หน้าต่างจะเริ่มต้นโดยเลือก Skill อย่างเป็นทางการ เมือง เรื่องราว และแนวทางสร้างสรรค์ไว้ให้แล้ว

- ขยาย “Skill อย่างเป็นทางการ” เพื่ออ่านสรุปและรายละเอียด แล้วเลือกแนวทางด้านภาพ
- ขยาย “โจทย์สร้างสรรค์” เพื่อค้นหาเมืองหรือเลือกตำแหน่งบนแผนที่
- สุ่มคำแนะนำใหม่ หรือแก้ไขเรื่องราวและแนวทางสร้างสรรค์โดยตรง
- ยืนยันตำแหน่งบนแผนที่ ภาษาที่รองรับ และสไตล์ของเอาต์พุต

ใช้แหล่งข้อมูลที่ตรวจสอบได้สำหรับประวัติศาสตร์ บุคคล และเหตุการณ์ ตรวจสอบรายละเอียดของ Skill ที่เลือกเพื่อดูภาษาและความยาวที่รองรับ

## 4. คัดลอกคำสั่งและเริ่มสร้าง {#_4-copy-the-instructions-and-create}

1. คลิก “คัดลอกทั้งหมด” ในส่วนพรอมต์
2. เปิดโฟลเดอร์โปรเจกต์ใน agent ในเครื่อง เริ่มงานใหม่ แล้ววางคำสั่งฉบับสมบูรณ์
3. ส่งคำสั่ง ระบุอินพุตที่ถูกขอ กำหนดค่า dependency แล้วเริ่มสร้าง

คำสั่งประกอบด้วย Skill ที่เลือก โจทย์สร้างสรรค์ รูปแบบ metadata ของผลงาน และสิทธิ์การอัปโหลด ให้ส่งต่อคำสั่งทั้งหมดเพื่อให้ agent สร้างและส่งผลงานได้

“กำลังเตรียม” หมายความว่ากำลังเตรียมสิทธิ์การอัปโหลด ใช้ “ลองใหม่” เพื่อเตรียมอีกครั้ง หรือ “กรอกโจทย์ให้ครบ” เพื่อเติมรายละเอียดที่ขาด

## 5. ติดตามความคืบหน้าการสร้าง {#_5-follow-creation-progress}

การสร้างอาจใช้เวลาตั้งแต่หลายสิบนาทีถึงหลายชั่วโมง ขึ้นอยู่กับ Skill โมเดล และความยาววิดีโอ และจะใช้เครดิตโมเดล ให้ agent ทำงานต่อเนื่องและอย่าให้คอมพิวเตอร์เข้าสู่โหมดพัก

เพิ่มคำสั่งเรื่องงบประมาณและความคืบหน้าในงานเดียวกัน:

```text
My model-call budget is [AMOUNT] USD. Ask before exceeding it.
Report the current step, saved files, and next step, then continue creation.
```

ใช้ MiniMax M3.1 Flash ผ่าน SandBase ตามที่กติกากิจกรรมปัจจุบันกำหนด ปฏิบัติตามข้อกำหนดของหน้ากิจกรรมและหน้าอัปโหลดเรื่องความยาว ความละเอียด คำบรรยาย และขนาดไฟล์

## 6. ส่งผลงานและตรวจสอบสถานะการตรวจสอบ {#_6-submit-and-check-review-status}

agent จะทำตามคำสั่งฉบับสมบูรณ์เพื่อใช้ไคลเอนต์อัปโหลดอย่างเป็นทางการ อัปโหลดวิดีโอ ภาพปก และ metadata แล้วส่งเข้ารับการตรวจสอบ

เปิด [ผลงานของฉัน](https://www.sandbase.ai/lab/event/aicityremix/mine?lang=en) เพื่อตรวจสอบความคืบหน้า:

| สถานะ | ขั้นตอนถัดไป |
|---|---|
| ฉบับร่าง | สร้างภาพยนตร์ให้เสร็จ อัปโหลดไฟล์ และส่งเข้ารับการตรวจสอบ |
| รอการตรวจสอบ | ติดตามสถานะการตรวจสอบ |
| อนุมัติแล้ว | เปิดหน้าผลงานสาธารณะและแชร์ |
| ขอให้แก้ไข | แก้ไขตามหมายเหตุการตรวจสอบแล้วส่งใหม่ |

สำหรับภาพยนตร์ที่มีอยู่แล้ว ให้เลือก “อัปโหลดวิดีโอที่มีอยู่” ในหน้ากิจกรรม กรอกรายละเอียด อัปโหลดวิดีโอและภาพปก แล้วส่งเข้ารับการตรวจสอบ

## 7. อัปโหลดต่อ {#_7-resume-an-upload}

หากสิทธิ์หมดอายุหรือการอัปโหลดถูกขัดจังหวะ ให้ดำเนินการต่อด้วยไฟล์เดิม:

1. เก็บวิดีโอ ภาพปก `entry.json` และโฟลเดอร์ทำงานไว้
2. ค้นหาฉบับร่างเดิมในผลงานของฉัน แล้วคลิก “อัปโหลดต่อ”
3. คัดลอกคำสั่งอัปโหลดต่อชุดใหม่ไปยังงานเดิมของ agent
4. ขอให้ agent อัปโหลดและส่งไฟล์ที่มีอยู่ จากนั้นตรวจสอบสถานะในผลงานของฉัน

## 8. แชร์ผลงานของคุณ {#_8-share-your-entry}

ในหน้าผลงานที่อนุมัติแล้ว คลิก “แชร์บน X” เพื่อเปิดหน้าเขียนโพสต์ที่กรอกข้อมูลไว้ล่วงหน้า ซึ่งมีลิงก์ผลงาน `#AICityRemix`, `@SandbaseAI` และโพสต์กิจกรรมอย่างเป็นทางการ

หากต้องการโพสต์วิดีโอ ให้คลิก “ดาวน์โหลดวิดีโอ” ก่อน เพิ่มไฟล์ในหน้าเขียนโพสต์ของ X ตรวจสอบข้อความ แล้วเผยแพร่
