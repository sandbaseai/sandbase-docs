# บทแนะนำ Skill {#skill-tutorials}

ใช้ Skills ของ SandBase กับ AI agent ในเครื่องของคุณเพื่อสร้างวิดีโอ แอนิเมชัน แผนที่ และโปรเจกต์อื่น ๆ เรียกดูตัวอย่างได้ใน [SandBase Lab](https://www.sandbase.ai/lab/) ดาวน์โหลด Skill แล้วรันเวิร์กโฟลว์ในโฟลเดอร์ทำงานของคุณเอง

## บทแนะนำ {#tutorials}

| บทแนะนำ | เวิร์กโฟลว์ |
|---|---|
| [ใช้ Skill ในเครื่อง](/guides/skills/local-use) | ดาวน์โหลด Skill เชื่อมต่อ SandBase ระบุโจทย์ และบันทึกผลลัพธ์ |
| [ร่วม AI City Remix](/guides/skills/ai-city-remix) | รับเครดิตของกิจกรรม เลือกเมืองและ Skill สร้างวิดีโอ และส่งเพื่อรับการตรวจสอบ |

## เตรียม workspace ของคุณ {#prepare-your-workspace}

- บัญชี SandBase
- AI agent บนคอมพิวเตอร์ของคุณที่รันคำสั่งและเข้าถึงไฟล์ได้
- โฟลเดอร์ทำงานสำหรับแพ็กเกจ Skill, input และไฟล์ที่สร้างขึ้น

Agent จะรัน Skill ในเครื่องและใช้ SandBase สำหรับการเรียกโมเดล กำหนดค่าการเชื่อมต่อผ่าน[การตั้งค่า](/setup/) และตรวจสอบการใช้งานได้ใน [Billing](https://www.sandbase.ai/console/billing)
