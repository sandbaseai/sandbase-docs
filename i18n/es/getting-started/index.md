# Primeros pasos con SandBase {#getting-started-with-sandbase}

SandBase ayuda a tu Agent a conectarse con el mundo real.

Si eres nuevo, empieza con la [Guía rápida](/getting-started/quickstart): crea una cuenta, configura una organización y haz una solicitud real.

Después, puedes usar SandBase de cuatro formas:

| Ruta | Ideal para | Qué obtienes |
|---|---|---|
| **Llamar a modelos y API** | Desarrolladores y creadores | Una solicitud funcional que puedes llamar desde tu aplicación |
| **Usar en el sitio web** | Probar una capacidad en el navegador | Una página de detalle del catálogo que puedes ejecutar sin escribir código |
| **Setup** | Quienes usan Codex, Claude, Cursor o Kiro | Modelos y API útiles dentro de tu app de IA |
| **Build Agent** | FDE y equipos que crean flujos de trabajo reutilizables | Un Agent que puedes probar y ejecutar en Sessions |

## Conceptos clave {#core-ideas}

### Catálogo {#catalog}
El catálogo del sitio web de SandBase es donde encuentras las capacidades:

- **Modelos** de razonamiento, texto, imagen, audio y video
- **API** de búsqueda, scraping, datos, multimedia, SaaS y conectores
- **Agents** como ejemplos listos para usar que puedes probar o clonar
- **Skills** como paquetes de tareas reutilizables para Agents

### Setup {#setup}

Setup lleva las capacidades a la herramienta de IA que ya usas.

Úsalo cuando quieras tener herramientas disponibles en Codex, Claude, Cursor o Kiro sin crear un Agent nuevo desde cero.

### Build Agent {#build-agent}

En Build Agent defines y pruebas tu propio Agent.

Un Agent combina un modelo, instrucciones, Skills y herramientas MCP en una unidad reutilizable y versionada.

Cuando funcione, puedes:

- ejecutarlo en Sessions desde tu aplicación
- revisar cada Session en la Console

## ¿Por dónde empiezo? {#where-should-i-start}

Si todavía no tienes una cuenta, empieza con la [Guía rápida](/getting-started/quickstart).

Si quieres llamar a una capacidad desde código, explora el [catálogo de modelos](https://www.sandbase.ai/models) o el [catálogo de API](https://www.sandbase.ai/apis) en tiempo real y luego usa la documentación y el ejemplo de solicitud correspondientes.

Si primero quieres probar una capacidad en el navegador, abre una página de detalle del catálogo en [sandbase.ai](https://www.sandbase.ai/models).

Si quieres herramientas en tu app de IA, empieza con [Setup](/setup/).

Si quieres un flujo de trabajo repetible, empieza con [Build Agent](/agents/).
