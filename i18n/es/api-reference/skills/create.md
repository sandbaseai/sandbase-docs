apiReference:
  title: Crear Skill
  operation: Skills
  method: POST
  path: /v1/skills
  description: Sube un paquete ZIP y crea la Skill en la versión 1. El cuerpo multipart debe contener exactamente una parte de archivo llamada files (o files[]), de hasta 5 MiB. El ZIP debe contener una sola carpeta de nivel superior con SKILL.md dentro (por ejemplo, zip -r release-notes.zip release-notes/), y el frontmatter de SKILL.md debe definir name y description. Un SKILL.md en la raíz del ZIP devuelve 400 invalid_request.
  groups:
    - title: Encabezados
      fields:
        - name: Idempotency-Key
          type: string
          required: false
          description: Opcional, de 1 a 128 bytes sin espacios al principio ni al final. Si se omite, el servicio genera una, por lo que una solicitud reintentada puede crear un duplicado. Envía tu propia clave estable para los reintentos.
    - title: Cuerpo de la solicitud
      description: multipart/form-data.
      fields:
        - name: files
          type: file
          required: true
          description: Archivo ZIP cuya única carpeta de nivel superior contiene SKILL.md.

    - label: Python (OpenAI SDK)
      language: python

        # Verified with openai-python 3.13.0 and 3.24.0. See /agents/openai-compatibility.
        import os
        from openai import OpenAI

        client = OpenAI(api_key=os.environ["SANDBASE_API_KEY"], base_url="https://api.sandbase.ai/v1")
        with open("release-notes.zip", "rb") as bundle:
            skill = client.skills.create(files=[("release-notes.zip", bundle.read(), "application/zip")])
        print(skill.id, skill.default_version)
