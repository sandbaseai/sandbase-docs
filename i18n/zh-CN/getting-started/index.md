# SandBase 入门 {#getting-started-with-sandbase}

SandBase 帮助你的 Agent 连接真实世界。

如果你是新用户，请从[快速开始](/getting-started/quickstart)入手：创建账户、设置组织，然后发起一次真实请求。

之后，你可以通过四种方式使用 SandBase：

| 方式 | 适用对象 | 你将获得 |
|---|---|---|
| **调用 Models 和 APIs** | 开发者和构建者 | 一个可从应用中调用的有效请求 |
| **在网站上使用** | 想在浏览器中试用某项能力的用户 | 一个无需写代码即可运行的目录详情页 |
| **Setup** | 使用 Codex、Claude、Cursor 或 Kiro 的用户 | 在 AI 应用中直接可用的 Models 和 APIs |
| **构建 Agent** | 构建可复用工作流的 FDE 和团队 | 一个可在 Session 中测试和运行的 Agent |

## 核心概念 {#core-ideas}

### 目录 {#catalog}
SandBase 网站上的目录是查找各项能力的地方：

- **Models**：用于推理、文本、图像、音频和视频
- **APIs**：用于搜索、抓取、数据、媒体、SaaS 和连接器
- **Agents**：可直接测试或克隆的现成示例
- **Skills**：供 Agent 使用的可复用任务包

### Setup {#setup}

Setup 将各项能力接入你已在使用的 AI 工具。

如果你希望在 Codex、Claude、Cursor 或 Kiro 中直接使用工具，而不想从零构建新的 Agent，就可以使用它。

### 构建 Agent {#build-agent}

在构建 Agent 中，你可以定义和测试自己的 Agent。

Agent 将模型、指令、Skills 和 MCP 工具组合成一个可复用、带版本的单元。

调试好之后，你可以：

- 从应用中在 Session 里运行它
- 在 Console 中查看每个 Session

## 从哪里开始？ {#where-should-i-start}

如果你还没有账户，请从[快速开始](/getting-started/quickstart)入手。

如果你想在代码中调用某项能力，请浏览实时的 [Models 目录](https://www.sandbase.ai/models)或 [APIs 目录](https://www.sandbase.ai/apis)，然后参考对应的文档和请求示例。

如果你想先在浏览器中试用某项能力，请在 [sandbase.ai](https://www.sandbase.ai/models) 上打开目录详情页。

如果你想在 AI 应用中使用工具，请从 [Setup](/setup/) 开始。

如果你需要可重复执行的工作流，请从[构建 Agent](/agents/) 开始。
