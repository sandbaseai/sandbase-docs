# Skill tutorials

Use SandBase Skills with your local AI agent to create videos, animations, maps, and other projects. Browse examples in [SandBase Lab](https://www.sandbase.ai/lab/), download a Skill, and run its workflow in your own working folder.

## Tutorials

| Tutorial | Workflow |
|---|---|
| [Use a Skill locally](/guides/skills/local-use) | Download a Skill, connect SandBase, provide a brief, and save the result. |
| [Enter AI City Remix](/guides/skills/ai-city-remix) | Claim event credits, choose a city and Skill, create a video, and submit it for review. |

## Prepare your workspace

- A SandBase account.
- An AI agent on your computer with command execution and file access.
- A working folder for the Skill package, inputs, and generated files.

The agent runs the Skill locally and uses SandBase for model calls. Configure your connection through [Setup](/setup/) and review usage in [Billing](https://www.sandbase.ai/console/billing).
