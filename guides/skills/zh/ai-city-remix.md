# AI City Remix 参赛教程

从活动页选择 Skill 和城市，将完整创作指令交给本地 Agent。制作完成后，Agent 上传视频、封面和作品信息，并提交审核。


## 准备工作

- 一个 SandBase 账号。
- 一个支持执行命令和读写文件的本地 Agent。
- 一个保存视频、封面和工作文件的项目文件夹。

首次配置本地环境，可先完成[在本地使用 Skill](/guides/skills/zh/local-use)。

## 1. 打开活动并领取额度

1. 进入 [AI City Remix](https://www.sandbase.ai/lab/event/aicityremix?lang=zh-CN)，查看当前[活动规则](https://www.sandbase.ai/lab/event/aicityremix?tab=rules&lang=zh-CN)。
2. 点击“免费领取 $5，立即制作”，按提示完成登录。
3. 系统领取活动额度并尝试自动兑换。查看余额和兑换状态；需要重试时，使用页面上的兑换入口。
4. 已领取后，点击“立即制作”进入创作弹窗。

领取时间、可用数量及资格以活动页面为准。模型调用按实际使用消耗额度，可在[账单页面](https://www.sandbase.ai/console/billing)查看。

## 2. 配置模型 API Key

账号没有可用 API Key 时，创作流程会显示“创建 API Key”窗口。

1. 查看页面说明的使用上限和有效期，点击“创建 API Key”。
2. 点击“使用此 Key 开始创作”。新建 Key 会随完整创作指令交给 Agent。
3. 将完整指令发送给自己信任的 Agent，并保存在私密工作环境中。

已有 Key 的用户，在本地 Agent 的安全配置或运行环境中配置 `SANDBASE_API_KEY`。Key 管理入口为 [API Keys](https://www.sandbase.ai/console/keys)。

## 3. 选择 Skill 和创作设定

弹窗默认选好官方 Skill、城市、故事和整体方向。

- 展开“官方 Skill”，查看简介与详情，选择需要的效果。
- 展开“创作设定”，搜索城市或在地图上选择地点。
- 点击“换一个”生成新的建议，也可以直接修改故事和整体方向。
- 确认城市位置、所选 Skill 支持的语言及作品形式。

历史信息、人物和事件应使用可核实的来源。不同 Skill 的语言和时长支持以详情说明为准。

## 4. 复制指令并开始制作

1. 在创作指令区域点击“复制全部”。
2. 在本地 Agent 中打开项目文件夹，新建任务并粘贴完整指令。
3. 发送指令，按 Agent 提示补充素材、完成依赖配置，然后执行制作。

指令包含所选 Skill、创作设定、作品信息格式和上传授权。保留完整内容，供 Agent 按流程制作及提交。

“准备中”表示正在取得授权；出现“重试”时重新准备，出现“补全设定”时填写缺少的内容。

## 5. 查看制作进度

制作可能需要数十分钟至数小时，取决于 Skill、模型和视频长度，并会消耗模型额度。制作期间保持 Agent 运行、电脑处于唤醒状态。

可以在原任务中补充预算与进度要求：

```text
本次模型调用预算为【填写金额】美元，预计超过前请先向我确认。
请汇报当前步骤、已保存的文件和下一步安排，然后继续制作。
```

按当前活动规则，通过 SandBase 使用 MiniMax M3.1 Flash 完成创作。成品时长、分辨率、字幕和文件大小按照活动规则及上传页面要求执行。

## 6. 提交并查看审核状态

Agent 根据完整指令调用官方上传客户端，上传视频、封面和作品信息，并提交审核。

打开[我的作品](https://www.sandbase.ai/lab/event/aicityremix/mine?lang=zh-CN)查看状态：

| 状态 | 下一步 |
|---|---|
| 草稿 | 完成制作、上传文件并提交审核。 |
| 等待审核 | 查看审核进度。 |
| 已上架 | 打开作品页面并分享。 |
| 需要修改 | 根据审核说明修改，再次提交。 |

已有成片时，可从活动页选择“上传已有视频”，填写作品信息，上传视频和封面后提交审核。

## 7. 继续上传已有作品

上传授权过期或上传中断时，使用原作品文件继续提交：

1. 保留视频、封面、`entry.json` 和工作文件夹。
2. 打开“我的作品”，找到同一草稿，点击“继续上传”。
3. 复制新的续传指令，交给原 Agent 任务。
4. 让 Agent 使用已有文件上传并提交，再回到“我的作品”确认状态。

## 8. 分享作品

在已上架作品页点击“分享到 X”，打开预填文案的发帖页面。文案包含作品链接、`#AICityRemix`、`@SandbaseAI` 和官方活动帖。

发布视频帖时，先点击“下载视频”，再在 X 发帖窗口添加视频文件，检查文案后发布。
