# Skill 教程

使用本地 Agent 执行 SandBase Skill，制作视频、动效、地图等作品。从 [SandBase Lab](https://www.sandbase.ai/lab/) 查看示例并下载 Skill，在自己的工作文件夹中完成创作。

## 教程目录

| 教程 | 操作流程 |
|---|---|
| [在本地使用 Skill](/guides/skills/zh/local-use) | 下载 Skill、连接 SandBase、填写创作需求并保存成品。 |
| [AI City Remix 参赛教程](/guides/skills/zh/ai-city-remix) | 领取活动额度、选择城市与 Skill、制作视频并提交审核。 |

## 准备工作

- 一个 SandBase 账号。
- 一个安装在电脑上、支持执行命令和读写文件的 Agent。
- 一个用于保存 Skill、输入素材和生成文件的工作文件夹。

Agent 在本地执行 Skill，通过 SandBase 调用模型。连接方式见 [Setup](/setup/)，使用额度可在[账单页面](https://www.sandbase.ai/console/billing)查看。
