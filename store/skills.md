# Skills

Skills are reusable task packages for Agents.

A Skill can include instructions, workflows, code, assets, and repeatable know-how. It helps an Agent do one job in a consistent way.

## When to use a Skill

Use a Skill when an Agent needs repeatable expertise, such as:

- researching a company
- reviewing code
- creating a structured report
- analyzing a page
- following a customer-support workflow

## Skills are for Build Agent

Skills are not usually installed directly into Setup as top-level tools.

Setup is for Models, APIs, and Services.

Skills are attached while building an Agent.

## Public and private Skills

Public Skills are shared examples.

Private Skills belong to your workspace.

You can inspect a public Skill, copy its ID, and attach it to an Agent.
